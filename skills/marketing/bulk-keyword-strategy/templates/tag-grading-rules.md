# 키워드 등급 (S/A/B/C/D) 룰

## 기본 등급 (검색량 기준)

| 등급 | 월간 총 검색량 (PC + Mobile) | 의미 |
|---|---|---|
| **S** | ≥ 10,000 | 메인 키워드 후보 — 상품명 앞쪽 배치 |
| **A** | ≥ 5,000 | 보조 키워드 — 상품명 + 태그 |
| **B** | ≥ 1,000 | 태그 활용 |
| **C** | ≥ 100 | 롱테일 — 블로그 / 광고 |
| **D** | < 100 | 거의 무용 (브랜드 키워드 / 너무 좁음) |

## 보정 (2단계)

### 1. 경쟁도 가중치 (검색광고 API `compIdx`)

| 경쟁도 | 가중치 | 사유 |
|---|---|---|
| 낮음 | × 1.2 | 진입 쉬움 — 더 가치 있음 |
| 중간 | × 1.0 | 표준 |
| 높음 | × 0.7 | 진입 어려움 — 가치 ↓ |

### 2. 시즌 보정 (DataLab 트렌드)

- 시즌성 키워드 (피크 vs 평균 ≥ 2.0)
- 현재 월이 피크 ±2개월 이내
- → 점수 × 1.3
- A/B 등급이면서 경쟁도 중하면 **S 승격**

## 메인 vs 보조 vs 태그

| 용도 | 선정 룰 | 개수 |
|---|---|---|
| **메인 키워드** | 점수 1위 (블록리스트 제외) | 1개 |
| **보조 키워드** | 점수 2~5위 | 4개 |
| **상품태그** | S → A → B → C 우선순위 | 10개 |

## 블록리스트 (제외 키워드)

다음 단어 포함 키워드는 자동 제외:
- 호환 침대명 (리안드림콧, 크리미드림, 베어블리, 쿠시노 등)
- "호환" 단어 자체
- 경쟁사 브랜드명
- 부정 단어 (가짜, 짝퉁 등)

## 시즌 일치 판정

```
peak_month: DataLab에서 추출한 검색량 피크 월 (1~12)
current_month: 오늘 월
diff = abs(peak - current)
시즌 일치 = (diff <= 2) or (diff >= 10)
```

> 12월 ↔ 1월 / 2월 ↔ 11월 같은 wrap 처리 포함.

## 등급 인플레 방지

- **S 키워드는 분기당 5개 미만 권장** — 너무 많으면 변별력 상실
- **D 키워드는 태그/카피에서도 제외** — 점유 가치 없음
- 등급은 자동, 운영팀장이 등록 전 시각 검토 필수
