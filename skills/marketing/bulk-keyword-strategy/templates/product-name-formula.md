# 네이버 스마트스토어 상품명 공식

## 핵심 규칙 (네이버 SEO 공식)

1. **50자 이내** (필수, 초과 시 검색 노출 패널티)
2. **수식어 / 자극 / 과장 표현 금지** ("최고", "1위", "100%", "베스트")
3. **띄어쓰기로 키워드 분리** — 띄어쓴 단어 단위로 인덱싱됨
4. **핵심 키워드 앞쪽 배치** — 50자 잘릴 때 뒤가 잘림
5. **같은 단어 반복 금지** — 패널티

## 공식 (Token 우선순위)

```
[브랜드] [시리즈명] [메인키워드] [보조1] [소재(짧게)] [보조2] [보조3] [타겟연령] [시즌]
```

| Token | 예시 | 비고 |
|---|---|---|
| 브랜드 | 썬데이허그 | 항상 첫 토큰 |
| 시리즈명 | 꿀잠 / ABC / 데일리 | 카테고리에 따라 |
| 메인키워드 | 아기 냉감패드 | S등급 키워드 |
| 보조1 | 아기 쿨매트 | A/B등급 |
| 소재 (짧게) | 듀라론 메쉬 | 2~3 단어 |
| 보조2 | 신생아 냉감패드 | |
| 보조3 | 양면 쿨매트 | |
| 타겟연령 | 신생아 / 아기 | |
| 시즌 | 여름 / 겨울 | 시즌성 제품만 |

## 카테고리별 시리즈명

| 카테고리 폴더 | 시리즈명 |
|---|---|
| sleep-products / sleeping-bags / newborn / outlet / set-products | **꿀잠** |
| abc | **ABC** |
| daily-look | **데일리** |

## 예시

### 1. 쿨링 메쉬 듀얼패드 (sleep-products)
```
썬데이허그 꿀잠 아기 냉감패드 쿨매트 듀라론 메쉬 신생아 양면 여름
(37자) ✅
```

### 2. 슬립색 코튼 메쉬 (sleeping-bags)
```
썬데이허그 꿀잠 아기 슬립백 신생아 코튼 메쉬 베이비 여름
(32자) ✅
```

### 3. 바디수트 (daily-look)
```
썬데이허그 데일리 아기 바디수트 신생아 우주복 오가닉 코튼 베이비 옷
(38자) ✅
```

## 금기어 (브랜드 가이드 V-02 / V-03)

자극형:
- `!!`, `!!!` (느낌표 연발)
- `대박`, `미친`, `역대급`, `초특가`, `베스트`, `강력`

과장형:
- `최고`, `1위`, `독보적`, `유일`, `절대`, `100%`, `완벽`

의료적:
- `치료`, `효능`

가격 단독:
- `할인`, `OFF` (단독 강조)

## 자가 점검

상품명 작성 후:
- [ ] 50자 이내?
- [ ] 메인 키워드 앞쪽 5~15자 사이?
- [ ] 금기어 0개?
- [ ] 같은 단어 반복 없음?
- [ ] 띄어쓰기 일관?
- [ ] 브랜드실장 검수 PASS?
