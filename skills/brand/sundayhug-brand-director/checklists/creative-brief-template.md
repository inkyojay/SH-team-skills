# 신규 캠페인 크리에이티브 브리프 템플릿

> 브랜드 실장이 신규 캠페인의 크리에이티브 방향성을 설정할 때 사용하는 표준 브리프.
> 채워진 브리프는 디자인·카피·콘텐츠 팀이 작업 전에 반드시 받아야 할 단일 진실(SSOT)이다.

## 3. 3축 정합 (Brand Essence Alignment)

이 캠페인은 다음 중 **어느 축이 메인이고 어느 축이 서브**인가:

- [ ] 메인: ⬜ 수면 과학  ⬜ 감성 디자인  ⬜ 프리미엄 경험
- [ ] 서브: ⬜ 수면 과학  ⬜ 감성 디자인  ⬜ 프리미엄 경험

**이유**:
```
[ 메인 축이 왜 적합한지 1~2 문장 ]
```

## 6. 비주얼 디렉션

### 컬러 팔레트
- **베이스 (필수)**: Cloud `#F7F5F2` / Warm Ivory `#FBF9F6` / Linen `#D9CFC3`
- **포인트 1**: ___________ (HEX: ______)
- **포인트 2**: ___________ (HEX: ______) — 선택

> 시즌 캠페인이면 Seasonal Accent 2~3색 중 1~2개 선택. 시즌 한정 컬러 명시.

### 무드 키워드 (1~2개 선택)

⬜ Dawn (새벽) — 청량/희망/시작
⬜ Dusk (황혼) — 따뜻/마무리/평화
⬜ Garden (정원) — 자연/생명/여유
⬜ Golden (골든아워) — 감성/온기/이상화
⬜ Moonlit (달빛) — 고요/숙면/밤

### 포토그래피 가이드
- 유형: ⬜ 제품 스틸컷  ⬜ 라이프스타일  ⬜ 플랫레이/디테일
- 자연광 필수 / 여백 60% 이상 / 인위적 보정 ❌

### 타이포 운영
- 영문 헤드라인: Cormorant Garamond Light/Regular
- 한글 본문: Noto Sans KR Light (강조만 Regular, Bold 700 ❌)

## 7. 보이스 톤 (4가지 모드 중 선택)

⬜ **수면 가이드 모드** — 친구에게 정보 알려주듯 ("실내 22도면 TOG 1.0이 딱이에요")
⬜ **공감 모드** — 옆집 언니처럼 ("4개월 수면 퇴행, 진짜 힘들죠")
⬜ **제품 설명 모드** — 감각적으로 ("대나무 원단이라 여름에도 뽀송해요")
⬜ **SNS 감성 모드** — 일상 한 컷 ("새벽 3시, 쿨쿨 자는 아기 옆 엄마")

## 9. 사용할 스킬 체인 (실행 순서)

```
[ 1 ] keyword-optimizer            ← SEO 카피 + 상품태그 발굴
   ↓
[ 2 ] product-analyzer (선택)        ← USP 정제
   ↓
[ 3 ] tone-match-local             ← 제품 사진 일괄 톤 통일 (디폴트 무드 또는 시즌 컬러 무드)
   ↓
[ 4 ] pdp-builder                  ← 자사몰 상세페이지
   ↓
[ 5 ] meta-ad-factory              ← 메타 광고 21종
   ↓
[ 6 ] sundayhug-marketing-planner   ← 시즌 캘린더 + 채널별 액션플랜
   ↓
[ 7 ] sundayhug-brand-director (이 스킬) ← 모든 산출물 최종 검수
```

## 부록: 브리프 작성 후 자동 트리거

브리프가 완성되면 브랜드 실장은 다음을 자동 제안:

1. 키워드 리서치 시작 (`keyword-optimizer`)
2. 톤 매칭이 필요한 사진 묶음 → `tone-match-local`로 일괄 변환 (Step 0에서 디폴트 vs 시즌 컬러 무드 선택)
3. 상세페이지 / 광고 / 마케팅 플랜 스킬 체인을 순서대로 실행하는 명령어 출력
4. 각 산출물이 나오면 `pre-publish-review.md`로 자동 검수
