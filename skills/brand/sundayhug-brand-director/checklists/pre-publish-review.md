# 출고 전 검수 체크리스트 (Pre-Publish Review)

> 브랜드 실장이 모든 출고물(상세페이지, 광고 소재, SNS 게시물, 카드뉴스, 패키징, 영상, 블로그 글 등)에 대해 **출고 직전** 통과시켜야 하는 체크리스트.

## 사용법

1. 검수 대상물(파일/URL/이미지/텍스트)을 받는다
2. 아래 9개 영역 × 평균 4~6개 항목, 총 50여 항목을 순차 체크
3. 각 항목 PASS / WARN / FAIL 판정
4. **FAIL 1개 이상이면 출고 불가**, 구체적 수정 지시
5. WARN 3개 이상이면 추가 리뷰 요청

---

## 🎨 1. Visual — 컬러 (5)

- [ ] Primary 5색(Midnight/Cloud/Warm Ivory/Moon/Linen)이 베이스에 있는가
- [ ] Signature 또는 Seasonal Accent 컬러가 적절히 포인트로 사용됐는가
- [ ] 형광색·원색·고채도 컬러가 없는가 (네온 핑크/그린, 원색 빨강·노랑 ❌)
- [ ] TOG 표시가 있다면 정확한 TOG 컬러 코드를 사용했는가 (0.3/1.0/2.5/3.5)
- [ ] 컬러 대비가 너무 강하지 않은가 (뮤트 톤 유지)

## 🔤 2. Visual — 타이포그래피 (4)

- [ ] 영문 헤드라인이 Cormorant Garamond를 사용하는가
- [ ] 한글 본문이 Noto Sans KR Light/Regular를 쓰고 Bold 700 떡칠을 피했는가
- [ ] 영문 본문이 DM Sans인가 (또는 적절한 산세리프)
- [ ] 폰트 크기·줄간격이 "숨 쉬는" 느낌인가 (꽉 채우지 않음)

## 📷 3. Visual — 포토그래피 (5)

- [ ] 자연광 기반의 따뜻한 톤인가
- [ ] 여백이 60% 이상인가
- [ ] 과도한 필터·인위적 보정이 없는가
- [ ] 아기 사진에 과한 스타일링이나 필터가 없는가
- [ ] 무드 키워드(Dawn / Dusk / Garden / Golden / Moonlit) 중 하나에 부합하는가

## 🗣️ 4. Voice — 어투 (5)

- [ ] "현명한 친구" 페르소나인가 (전문적이되 어렵지 않음)
- [ ] 느낌표가 과도하지 않은가 (`!!`, `!!!` 연발 ❌)
- [ ] 급박한 어조가 없는가 ("지금 바로!", "대박!", "미친!" ❌)
- [ ] 공감 → 정보 → 가치 순서로 흐르는가 (제품 스펙부터 들이밀지 않음)
- [ ] 한글 본문 안에 영문 전문 용어가 번역 없이 남아있지 않은가 (TOG는 예외, 단 본문에 풀이 필요)

## 🚫 5. Voice — 금지 표현 (5)

- [ ] "최고", "독보적", "유일한", "1위", "베스트" 등 과장 표현이 없는가
- [ ] 경쟁 브랜드 직접 비교·비하가 없는가
- [ ] 가격 할인을 단독으로 부각하는 톤이 아닌가 ("30% OFF" 단독 배너 ❌)
- [ ] 연예인 광고 톤·커머스 자극 톤이 아닌가
- [ ] 의료적 효능을 단정하지 않는가 ("불면증 치료", "100% 안전" 등 ❌)

## 💎 6. Brand Essence — 3축 정합 (5)

검수 대상물이 다음 3축 중 **최소 1축**과 명확히 연결되어야 함:

- [ ] 수면 과학 (Sleep Science): TOG / 온도 / 월령 / 수면 퇴행 / 데이터
- [ ] 감성 디자인 (Sensory Design): 시즌 컬러 / 무드 / 인스타 감성 / 컬렉션
- [ ] 프리미엄 경험 (Premium Experience): 패키징 / 선물 / 언박싱 / 손글씨 카드

미션과 연결됨이 느껴지는가:
- [ ] "아기의 깊은 잠 → 부모의 여유 → 가족 일상" 흐름이 암묵적으로 깔려 있는가
- [ ] 제품을 단순 기능이 아니라 "수면 솔루션의 일부"로 제시하는가

## 🏷️ 7. Tagline / Headline (3)

- [ ] 메인 카피가 `Sleep, Simplified.` / `잠, 더 쉽게.` 정신과 일치하는가 (변형 OK)
- [ ] 캠페인성 카피가 감성형 변형 4종 패턴 중 하나인가
  - "오늘 밤, 온 가족이 잠드는 시간"
  - "과학이 설계한 포근함"
  - "아기가 잠든 밤, 엄마의 일요일"
- [ ] 태그라인이 카테고리 단어("아기침대", "슬립백") 단독이 아닌가

## 🎯 8. 타겟 적합성 (4)

- [ ] 30대 초중반 첫째 엄마가 봤을 때 어색함이 없는가
- [ ] 정보형(데이터/근거) + 감성형(비주얼/경험) 둘 다 충족하는가
- [ ] 출산선물 구매자가 봐도 어색하지 않은가
- [ ] 네이버 카페 / 인스타 두 채널 동시 노출에 톤이 맞는가

## 📦 9. 채널별 톤 (Instagram / Threads / 네이버 / 상세페이지)

### 인스타 피드
- [ ] 캡션이 짧고 감성적인가 (장황한 스펙 X)
- [ ] 비주얼이 룩북 스타일인가
- [ ] 해시태그에 `#썬데이허그 #오늘밤도잘자` 류 브랜드 태그 포함

### Threads
- [ ] 친구에게 말하듯 캐주얼한가
- [ ] 한 게시물 = 한 인사이트 또는 한 순간

### 네이버 블로그
- [ ] 검색 SEO 의식 (롱테일 키워드 자연 삽입)
- [ ] 정보형 본문이 "현명한 친구" 톤
- [ ] 마지막에 부드러운 제품 안내 (광고 톤 X)

### 상세페이지
- [ ] HERO가 감성 후킹 한 문장 (스펙 직접 X)
- [ ] WHY 섹션이 페인 → 인사이트 → 솔루션 흐름
- [ ] FINAL CTA가 자극적 할인 어조가 아닌 가치 제안

## 🚦 최종 판정

```
PASS  : 모든 항목 ✓
WARN  : ≤ 2개 항목 부분 충족
FAIL  : ≥ 1개 항목 부적합
```

### FAIL 시 출력 양식

```
판정: FAIL

위반 항목 (n개):
1. [영역] 항목 — 무엇이 / 왜 위반인가 / 어떻게 수정
2. ...

수정 후 재검수 요청 부탁드립니다.
```

### PASS 시 출력 양식

```
판정: PASS ✅

브랜드 정합도: 우수
- 강점: [구체적으로 잘된 점 2~3개]
- 다음 단계: [출고 채널 / 시점 추천]
```
