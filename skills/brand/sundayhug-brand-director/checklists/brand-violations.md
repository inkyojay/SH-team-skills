# 브랜드 위반 체크리스트 (DO / DON'T 위반 패턴 카탈로그)

> 브랜드 실장이 검수 시 가장 자주 마주치는 위반 패턴을 카테고리별로 정리.
> 새 위반이 발견되면 이 파일에 추가하여 학습.

## 🔴 Critical Violations (즉시 reject)

### V-01. 형광/원색 사용
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 네온 핑크/그린 | `#FF00FF`, `#00FF00` | Primary/Signature 팔레트의 뮤트 톤으로 |
| 원색 빨강/노랑 | `#FF0000`, `#FFEB00` | Soft Apricot `#E8C9A8` 또는 Blush `#DEB5A8` |
| 고채도 보라 | `#9C27B0` | Dusty Lavender `#C4B5CB` |

### V-02. 자극적 어조
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 느낌표 연발 | "할인!! 지금!!", "대박!!!" | 조용한 평서문 |
| 자극 단어 | "대박", "미친", "역대급", "초특가" | "이번 시즌 새로", "조용히 만나보세요" |
| 급박 어조 | "지금 바로!", "마감 임박!", "한정 100개!" | "오늘 밤, 천천히 만나보세요" |
| 명령형 | "지금 사세요!", "놓치지 마세요!" | "만나보시면 좋겠어요" |

### V-03. 과장 / 단정
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 최상급 단정 | "최고", "독보적", "유일한", "1위" | "우리가 자신 있는", "오래 다듬어 온" |
| 의료적 효능 | "불면증 치료", "100% 안전", "효과 보장" | "수면에 도움이 되는", "안심하고 쓰실 수 있는" |
| 절대적 표현 | "절대 못 깨", "완벽한 수면" | "더 깊이 잠드는", "조금 더 편안한" |

### V-04. 경쟁사 비교/비하
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 직접 비교 | "A브랜드보다 5배" | 우리만의 가치로 환원 |
| 비하 | "싸구려 슬립백 그만" | 비교 자체를 빼고 우리의 본질만 |
| 카테고리 흠집 | "흔한 그런 제품과는 달라요" | "이 카테고리에서 우리가 주목한 것은" |

## 🟡 Major Violations (수정 필요)

### V-05. 비주얼 톤 어긋남
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 과한 보정 | HSL 채도 +50, 명도 -30 | 자연광 그대로, 후보정 최소 |
| 좁은 여백 | 텍스트가 가장자리 5px 이내 | 여백 60% 이상 확보 |
| 폰트 굵기 떡칠 | 본문 전체 Bold 700 | Light 300 본문 + 강조만 Regular 400 |
| 폰트 종류 위반 | 한글 굴림체, Arial | Noto Sans KR / Cormorant Garamond / DM Sans |
| 인위적 스타일링 | 아기 사진 화려한 의상/액세서리 풀 세팅 | 자연스러운 일상 컷 |

### V-06. 카피 톤 어긋남
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 스펙 직접 들이밀기 | "TOG 1.0 / 폴리에스터 100%" | "봄가을 22도에 딱 좋은 두께" |
| 영문 전문용어 방치 | "Bamboo Viscose 97%" | "대나무 원단 97% (피부에 닿는 느낌이 부드러워요)" |
| 마케팅 클리셰 | "엄마라면 누구나" | 구체적 페르소나 ("4개월 첫째맘이라면") |
| 가격 단독 부각 | "29,800원!!" | "선물세트 29,800원 — 작은 선물이지만" |

### V-07. 미션 단절
| 패턴 | 예시 | 수정 방향 |
|---|---|---|
| 기능만 강조 | "방수, 통기, 스트레치" | 기능 → 페어런트 경험 → 가족 일상으로 연결 |
| 제품 = 단품 | "이 슬립백은 ..." | "이 슬립백이 만드는 깊은 잠은 ..." |
| 3축 누락 | 수면 과학 / 감성 / 프리미엄 어느 것도 없음 | 최소 1축 명시적으로 |

## 🟢 Minor Violations (개선 권장)

### V-08. 채널 톤 부정합
| 채널 | 자주 어긋나는 패턴 | 가이드 |
|---|---|---|
| 인스타 피드 | 캡션이 너무 김(500자+) | 100~250자, 감성 한 줄 + 짧은 본문 |
| Threads | 광고처럼 됨 | 친구가 혼잣말 하듯 |
| 네이버 블로그 | SEO 키워드 떡칠 | 자연스럽게 흐르는 글 + 키워드 자연 삽입 |
| 자사몰 PDP | HERO에 스펙 직접 | HERO = 감성 후킹 한 문장 |
| 메타 광고 | 21개가 다 비슷 | 톤 3종(이성형/감성형/공감형) × 레이아웃 다양화 |

### V-09. 패키징 일관성
- 박스 컬러가 메인 라인업과 다른 톤
- 동봉물(수면 가이드 카드, 손글씨 카드 등) 빠짐
- 해시태그 안내 누락 (`#썬데이허그 #오늘밤도잘자`)

### V-10. 콘텐츠 3 Pillars 편향
- Pillar 1(수면 사이언스)만 너무 많음 → 무겁게 느껴짐
- Pillar 2(시즌 비주얼)만 → 깊이 없음
- Pillar 3(리얼 후기)만 → 광고 톤
- 권장 비율: Pillar 1 : 2 : 3 = **3 : 4 : 3** 또는 **2 : 5 : 3**
