# SundayHug Brand DNA — Quick Reference (브랜드 실장 1차 컨텍스트)

> 이 파일은 브랜드 실장이 매번 빠르게 로드하는 압축 카드.
> 풀 가이드는 같은 폴더의 `sundayhug-brand-project.md` (10,500자) / `sundayhug-brand-guide.html` (60KB).

## 1. Brand Essence (절대 흔들리지 않는 3축)

1. **수면 과학 (Sleep Science)** — TOG 등급, 실내 온도별 착장 가이드, 데이터 기반
2. **감성 디자인 (Sensory Design)** — 인스타에 올리고 싶은 육아템, 시즌별 컬러 컬렉션
3. **프리미엄 경험 (Premium Experience)** — 출산선물로 받았을 때 가장 기분 좋은 브랜드

**미션**: "아기의 깊은 잠이 곧 부모의 여유가 되고, 그 여유가 가족의 일상을 바꾼다."

**메인 태그라인**: `Sleep, Simplified.` / `잠, 더 쉽게.`

## 2. 페르소나 / 보이스

- **페르소나**: "현명한 친구" — 전문적이지만 어렵지 않고, 따뜻하지만 과하지 않음
- **타겟**: 30대 초중반 첫째 엄마 (네이버 카페 + 인스타 감성, 정보형 + 감성형 교차)
- **가격대**: 3만~7만원 (국내 프리미엄)

## 3. 컬러 시스템 (숨 쉬듯 외우기)

### Primary (상시 — 어떤 출고물이든 베이스)

|---|---|---|
| Midnight | `#2C2C3A` | 본문 강조/제목 |
| Cloud | `#F7F5F2` | 배경 |

| Moon | `#E8DFD4` | 서브 배경 |
| Linen | `#D9CFC3` | 자연 텍스처 |

### Signature (시그니처 — 시즌 컬렉션)
Dusty Lavender `#C4B5CB` / Sage `#B5C4B1` / Soft Apricot `#E8C9A8` / Misty Blue `#B3C5D3` / Blush `#DEB5A8`

### Seasonal Accent (시즌 한정 — 매 시즌 2~3색만)
Golden Hour `#D4A574` / Deep Sage `#7A8F76` / Dusty Rose `#C09B8D` / Slate Blue `#8A9BB0`

> ❌ **금지 컬러**: 형광색, 원색, 강한 채도. 빨강·노랑·녹색 원색 셀 금지.

## 4. 타이포그래피

| 용도 | 폰트 | 무게 |
|---|---|---|
| 영문 헤드라인 | Cormorant Garamond | Light 300 / Regular 400 |
| 한국어 본문 | Noto Sans KR | Light 300 (본문), Regular 400 (강조) |
| 영문 본문 | DM Sans | Light 300 / Regular 400 / Medium 500 |

> ⚠️ Bold 700 최소화 — "가벼움"이 브랜드 톤. 한글에서 굵은 글씨 남용 금지.

## 5. 포토그래피 무드 키워드

**핵심**: 자연광 + 뮤트 톤 + 여백 60% 이상

**무드 키워드**: Dawn(새벽) / Dusk(황혼) / Garden(정원) / Golden(골든아워) / Moonlit(달빛)

| 유형 | 가이드 |
|---|---|
| 제품 스틸컷 | 자연광 + 린넨 배경 + 소재 질감 + 여백 60%+ |
| 라이프스타일 | 자고 있는 자연스러운 순간, 포즈 X, 따뜻한 톤 자연광 |
| 플랫레이 | 내려다본 앵글, 통일된 배경, 패키징 함께 → 선물 느낌 극대화 |

## 6. 보이스 & 톤 — 4가지 핵심 상황

| 상황 | DO | DON'T |
|---|---|---|
| 수면 가이드 | "실내 온도가 22도라면 TOG 1.0에 반팔 내의면 딱 좋아요." | "본 제품은 열전달 계수 1.0 TOG 등급으로서..." |
| 공감 | "4개월 수면 퇴행, 진짜 힘들죠." | "수면 퇴행기에는 일관된 수면 루틴을 유지하세요!" |
| 제품 설명 | "대나무 원단이라 여름에도 뽀송해요." | "프리미엄 대나무 레이온 97% 함유! 흡습속건! 항균!" |
| SNS | "오늘 새벽 3시, 쿨쿨 자는 아기 옆에서 엄마도 눈이 스르르" | "대박 할인! 슬립백 30% OFF!! 지금 바로 구매!!!" |

## 8. DO / DON'T 마스터

### ✅ DO
- 자연광 기반 따뜻한 톤 사진
- 여백을 충분히 둔 "숨 쉬는" 디자인
- 수면 과학 데이터를 쉬운 말로
- 뮤트 톤 컬러 팔레트 일관 유지
- "지금 만나보세요" 톤
- 출산선물 경험 고려한 패키징
- 매 시즌 새로운 컬러 한정 드롭
- 고객 후기를 진정성 그대로 공유

### ❌ DON'T
- 형광색, 원색 강렬한 컬러
- 느낌표 과다, 급박한 톤
- 가격 할인만 강조하는 배너
- 전문 용어 번역 없이 사용
- 과도한 포토샵 보정/인위적 사진
- "최고", "독보적", "유일한" 등 과장
- 경쟁 브랜드 직접 비교/비하
- 아기 사진에 과도한 필터

## 9. 콘텐츠 3 Pillars

1. **Pillar 1 — 수면 사이언스**: 월령별 수면 패턴 / 실내 온도별 착장 / 수면 퇴행 (네이버 블로그 + 인스타 카드뉴스)
2. **Pillar 2 — 시즌 비주얼**: 시즌 컬러 드롭 / 티저→프리오더→출시 사이클 (인스타 피드 = 룩북)
3. **Pillar 3 — 리얼 후기**: 포토 리뷰 이벤트 / 사용 전후 비교 / 슬립로그 (UGC)

## 10. 포지셔닝 한 줄

> "한국 아기 수면 전문가 — 수면 솔루션 + 감성 컬러 + 프리미엄 선물"

## 11. 빠른 검수 시그널 (브랜드 실장 즉시 반응)

검수 시 다음이 보이면 **즉시 reject**:
- 🚫 형광 핑크/네온 그린/원색 빨강
- 🚫 `!!!` `!!` 연속 느낌표 / `대박` `미친` 같은 자극 단어
- 🚫 한글 Bold 700 떡칠
- 🚫 `최고` `독보적` `유일한` `1위` 같은 과장
- 🚫 인위적 색감 보정 / 과한 채도
- 🚫 가격 할인만 강조하는 배너 톤
- 🚫 직접적 경쟁사 비교/비하
- 🚫 영어 전문 용어 (TOG 외) 번역 없이 사용
