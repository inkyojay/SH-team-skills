# Cafe24 자사몰 업로드 SOP

## 신제품 등록 흐름

```
1. 상품기획팀장이 신제품 brief 전달
   ↓
2. 디자이너가 제품 사진 / 패키징 시안 제공
   ↓
3. 마케팅팀장 + pdp-builder로 PDP HTML 생성
   ↓
4. 브랜드실장 검수 → PASS 받음 ★
   ↓
5. tone-match-local로 사진 톤 통일 (필요시)
   ↓
6. pdp-capture-prep으로 캡처 전처리
   ↓
7. pdp-section-capture로 섹션별 PNG 분할
   ↓
8. Cafe24 관리자 페이지에서 등록
   - 상품 정보 (가격 / 옵션 / 재고)
   - 상세페이지 PNG 업로드 (섹션 순서대로)
   - 카테고리 / 진열 위치
   - 키워드 태그 (마케팅팀장 keyword-optimizer 결과)
   ↓
9. 노출 테스트 (자사몰 검색)
   ↓
10. 운영팀장 등록 완료 보고 → CEO + 마케팅팀장
```

## 필수 체크리스트

### 등록 전
- [ ] 브랜드실장 검수 PASS 확인 (이메일/슬랙 인증)
- [ ] 모든 PNG 파일 1080px 이상
- [ ] 색감 통일 확인 (`tone-match-local` 적용 여부)
- [ ] 제품 정보 정합성 (가격 / 사이즈 / TOG / 색상)
- [ ] SKU 코드 명명 규칙 준수
- [ ] 상품태그 10개 (`keyword-optimizer` 결과 활용)

### 등록 중
- [ ] 모바일 미리보기 확인 (자사몰 트래픽 80%+ 모바일)
- [ ] 옵션별 재고 정확
- [ ] 배송비 정책 정합

### 등록 후
- [ ] 자사몰 검색 결과 노출 확인 (브랜드명 + 키워드)
- [ ] 첫 24시간 PV / 장바구니 전환 모니터링
- [ ] 결제 흐름 직접 테스트

## 시즌 캠페인 시

추가 작업:
- [ ] 메인 배너 교체 (디자이너)
- [ ] 시즌 컬러 카테고리 페이지 신설
- [ ] 프로모션 코드 / 쿠폰 발급
- [ ] 사은품 자동 추가 룰 설정

## 흔한 함정

1. **검수 안 거친 페이지 등록** — 절대 X (브랜드실장 PASS 필수)
2. **모바일 확인 빠뜨림** — 자사몰 트래픽 대부분 모바일
3. **이미지 압축 과다** — 1080px 이하 X (선명도 손실)
4. **카테고리 누락** — 검색 노출에 영향
5. **재고 동기화 X** — Cafe24 vs 스마트스토어 vs 쿠팡 재고 불일치 사고
