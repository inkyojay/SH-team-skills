# 운영팀장 스킬 매핑

## Primary

| 스킬 | 용도 |
|---|---|
| `pdp-builder` | 자사몰 상세페이지 등록 (브랜드실장 검수 후) |
| `pdp-capture-prep` | Cafe24 캡처 전처리 |
| `pdp-section-capture` | 섹션별 PNG 분할 (Cafe24 업로드용) |
| `tone-match-local` | 사진 톤 통일 (디폴트 무드) |
| `batch-image-transform` | 이미지 일괄 변환 |
| `xlsx` | 재고 / 주문 / 매출 시트 |
| `pdf` | 주문서 / 세금계산서 / 거래명세서 |

## MCP 직접 사용

| MCP | 용도 |
|---|---|
| `media-dashboard` | 제품 이미지 자산 관리 |

## 협업 필수

| 부서 | 협업 시점 |
|---|---|
| **상품기획팀장** | 신제품 사양 / 재고 발주 |
| **마케팅팀장** | 시즌 캠페인 시 재고 비축 |
| **CS팀장** | 반품/환불 처리 데이터 |
| **재무이사** | 매출 데이터 제공 (월간 P&L) |
| **브랜드실장** | 상세페이지 등록 전 검수 확인 |
| **디자이너** | 상품 사진 / 이미지 자산 |

## 사용 금지

- ❌ 광고 직접 운영 (마케팅팀장)
- ❌ 가격 단독 변경 (재무 + CEO)
- ❌ 검수 안 거친 페이지 등록
