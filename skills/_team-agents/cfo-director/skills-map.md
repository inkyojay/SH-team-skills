# 재무이사 스킬 매핑

## Primary

| 스킬 | 용도 |
|---|---|
| `naver-ads-reporter` | 네이버 광고 ROAS / 비용 자동 리포트 |
| `xlsx` | P&L · 시뮬레이션 · 현금흐름 시트 |
| `data-report-analyzer` (sub-agent) | CSV/엑셀 종합 분석 |
| `new-product-planner` | 신제품 수익 시뮬레이션 (13탭 중 가격/수익 부분) |

## Secondary

| 스킬 | 용도 |
|---|---|
| `pdf` | 세금계산서 / 회계 문서 처리 |
| `pptx` | 분기 IR / 이사회 발표 |
| `competitive-intelligence` | 경쟁사 가격대 비교 |

## MCP 직접 사용

| MCP | 용도 |
|---|---|
| `naver-search.search_shop` | 경쟁사 가격 모니터링 |

## 사용 금지

- ❌ 광고 카피/디자인 직접 제작 금지 (마케팅팀장/디자이너 영역)
- ❌ 마케팅 채널 단독 결정 금지 — 마케팅팀장과 협의

## 핵심 KPI 정의

| KPI | 정의 | 목표 |
|---|---|---|
| **ROAS** (가중) | 광고매출 / 광고비, 채널별 가중평균 | 4.0+ |
| **CAC** | 광고비 / 신규 고객수 | LTV의 1/3 이하 |
| **LTV** | 고객당 12개월 누적 매출 | 분기별 갱신 |
| **Payback Period** | CAC / 월 평균 객단가 | 6개월 이내 |
| **마진율** | (매출 - 원가) / 매출 | 50%+ |
| **영업이익률** | 영업이익 / 매출 | 15%+ |
| **재고일수** | 재고 / 일 평균 매출 원가 | 60~90일 |

## 채널별 ROAS 임계치

| 채널 | 최소 허용 ROAS | 일시정지 트리거 |
|---|---|---|
| 메타 광고 | 3.0 | 2주 연속 < 2.5 |
| 네이버 검색광고 | 4.0 | 1주 < 3.0 |
| 네이버 쇼핑광고 | 5.0 | 1주 < 4.0 |
| 카카오 광고 | 3.0 | 2주 연속 < 2.5 |

→ 트리거 발동 시 마케팅팀장에게 즉시 알림 + CEO에 cc.
