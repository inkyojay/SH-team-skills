# 재무이사 주기적 작업

## 매주

### 1. 주간 ROAS 리포트 — 매주 금 17:23

**Cron**: `23 17 * * 5`

**프롬프트**:
```
이번 주(월~금) 채널별 광고 ROAS 리포트:

`naver-ads-reporter` 자동 실행 + 메타 광고 데이터 종합.
채널 분리: 메타 / 네이버 검색 / 네이버 쇼핑 / 카카오.

각 채널별:
- 노출/클릭/비용/매출/ROAS/CTR/CPC
- 임계치 미달 캠페인 빨강 표시 + 일시정지 권고
- 지난주 대비 (WoW)

종합:
- 가중 평균 ROAS
- 다음 주 예산 재배분 제안
- CEO 알림 신호 (있다면)

저장: ~/Desktop/team-skills/리포트/cfo/weekly-roas/{YYYY-Wnn}.md
```

### 2. 주간 현금 예측 — 매주 월 9:43

**Cron**: `43 9 * * 1`

**프롬프트**:
```
4주 현금흐름 예측 (보수/기본/낙관 3시나리오):

- 예상 매출 (운영팀장 데이터 + 시즌 가중)
- 예상 광고비 (마케팅팀장 계획)
- 예상 결제일 (재고 발주 / 인건비 / 임차료)
- 환불/반품 예측

저장: ~/Desktop/team-skills/리포트/cfo/cash-flow/{YYYY-MM-DD}.xlsx
4주 후 잔고가 임계치 미달이면 CEO 즉시 알림.
```

## 매월

### 3. 월간 P&L — 매월 1일 10:13

**Cron**: `13 10 1 * *`

**프롬프트**:
```
전월 P&L 종합:

매출 (채널별)
- 자사몰 / 스마트스토어 / 쿠팡 / 카카오 / 기타

원가
- 제품 원가 (운영팀장 데이터)
- 물류비

마케팅 비용
- 채널별 광고비
- 인플루언서 / 체험단

운영 비용
- 인건비 / 임차료 / 시스템 / 기타

영업이익 / 마진율 / ROI 종합

추가 분석:
- CAC / LTV / Payback (지난 12개월 트렌드)
- 채널별 수익성 순위

출력: xlsx (시트별 분리) + md 1페이지 요약.
저장: ~/Desktop/team-skills/리포트/cfo/monthly-pnl/{YYYY-MM}.xlsx + .md
```

## 매분기

### 4. 분기 IR / 이사회 자료 — 분기 마지막 주 목 14:13

**Cron**: `13 14 22-31 3,6,9,12 4`

**프롬프트**:
```
분기 IR 자료 (이사회 / 투자자용):

1. 분기 매출/영업이익 vs 전분기 vs 전년동기
2. 채널별 / 카테고리별 매출 비중
3. 마케팅 효율 (ROAS / CAC / LTV)
4. 핵심 SKU 수익성 TOP 10
5. 다음 분기 가이던스 (보수/기본/낙관)
6. 자금 운용 현황 (잔고 / 자본금 / 부채)

출력: pptx 12장 + 부록 xlsx.
저장: ~/Desktop/team-skills/리포트/cfo/quarterly-ir/{YYYY-Qn}/
```
