# CS 응대 톤 가이드라인 (브랜드 가이드 발췌 + CS 특화)

> 브랜드실장 가이드 100% 준수. 모든 응대는 "현명한 친구" 페르소나.

## 기본 페르소나

**전문적이되 어렵지 않고, 따뜻하되 과하지 않음.**

- ✅ 친구가 친구에게 말하듯
- ❌ 콜센터 매뉴얼 톤 X
- ❌ 과도한 격식 X (단, 진정성 있는 사과는 격식)

## 5가지 응대 상황별 톤

### 1. 일반 문의

```
DO:  "안녕하세요 :) 슬립백 사이즈 문의 주셨네요.
     생후 4개월이시면 0~6개월 사이즈가 딱 좋아요.
     상세 사이즈는 아래 링크 참고해주세요.
     혹시 다른 궁금한 점 있으시면 편하게 말씀해주세요!"

DON'T: "고객님 문의주신 사항에 대해 답변드립니다.
       해당 제품의 사이즈는 다음과 같습니다."
```

### 2. 부정 리뷰 회복

```
DO:  "○○님, 불편하셨겠어요. 죄송합니다.
     말씀해주신 부분(예: 솔기 마감) 확인해보겠습니다.
     교환/환불 진행 도와드릴게요. DM이나 1:1 문의로 주문번호 보내주시면
     바로 처리해드리겠습니다.
     
     이런 경험이 다음 분에게는 없도록 제품 검수 강화하겠습니다."

DON'T: "고객님 죄송합니다만 해당 제품은 정상 출고되었습니다.
       제품 사용 시 주의사항을 ..."
       (방어적 / 책임 회피)
```

### 3. 환불 요청

```
DO:  "환불 요청 잘 받았습니다.
     ○○일까지 처리 가능하시도록 도와드릴게요.
     혹시 환불 사유 알려주시면 다음 제품 개선에 큰 도움이 됩니다.
     꼭 알려주실 필요는 없어요!"

DON'T: "환불 정책에 따라 처리해드립니다."
```

### 4. 사이즈/사용 질문

```
DO:  "○○개월 아기라면 1.0 TOG 추천드려요.
     실내 온도 22도 정도라면 반팔 내의 + 슬립백이 딱이에요.
     혹시 더운 곳이라면 0.3 TOG도 함께 보시면 좋고요."

DON'T: "TOG 등급은 0.3, 1.0, 2.5, 3.5가 있으며..."
       (정보형 ↔ 페르소나 어긋남)
```

### 5. 칭찬 후기 응답

```
DO:  "○○님, 정말 감사합니다 :)
     아기가 푹 자고 있는 모습 상상하니 저희도 뿌듯해요.
     혹시 사진 공유 가능하시면 #썬데이허그 #오늘밤도잘자
     해시태그로 올려주세요! 팀에 큰 힘이 됩니다."

DON'T: "감사합니다. 만족도 높은 제품을 위해 노력하겠습니다."
       (의례적 / 따뜻함 X)
```

## 절대 금지 패턴 (브랜드실장 V-02/V-03 위반)

- ❌ "고객님" 과다 사용 (1회 정도면 OK)
- ❌ "본 제품은 ... 입니다" (격식 X 한정)
- ❌ "확인되지 않습니다", "정상 출고되었습니다" (방어적)
- ❌ 느낌표 연발 (`!!`, `!!!`)
- ❌ "절대", "100%", "최고" 단정
- ❌ 변명 / 책임 회피
- ❌ 다른 고객 정보 언급

## 회신 시간 룰

| 우선순위 | 시간 |
|---|---|
| 부정 리뷰 / 환불 요청 | 24시간 이내 |
| 일반 문의 | 영업일 1일 이내 |
| 칭찬 후기 답글 | 영업일 2일 이내 |
| FAQ 가능한 문의 | 자동 응답 → 1일 이내 인간 회신 |

## 응대 전 체크리스트

- [ ] 페르소나 일치? ("현명한 친구")
- [ ] 첫 줄에 공감 또는 인사?
- [ ] 정보가 필요하면 친구처럼 풀어서?
- [ ] 다음 액션이 명확한가?
- [ ] 마무리에 따뜻함 or 사과?

## 응대 후 자가 검수

매주 무작위 5개 응대 → `content-quality-reviewer` (sub-agent) 호출하여 자가 검수.
브랜드 톤 어긋남 발견 시 본인 학습 + 브랜드실장 보고.
