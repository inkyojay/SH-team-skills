# VOC 카테고리 분류표

> 모든 VOC를 5개 메인 카테고리 / 25개 서브 카테고리로 분류.
> 매주 빈도 집계 → 부서별 개선 신호.

## 1. 제품 관련

| 서브 | 정의 | 책임 |
|---|---|---|
| 1-1. 사이즈 | 작다/크다 | 상품기획 |
| 1-2. 소재/촉감 | 까칠/까슬/거칠 | 상품기획 |
| 1-3. 마감 / 봉제 | 솔기 풀림, 단추 떨어짐 | 상품기획 + 운영 |
| 1-4. 컬러 / 디자인 | 사진과 다름, 색바램 | 디자이너 + 상품기획 |
| 1-5. 기능 | TOG / 통기성 / 신축성 | 상품기획 |

## 2. 배송 관련

| 서브 | 정의 | 책임 |
|---|---|---|
| 2-1. 배송 지연 | 약속일 초과 | 운영 |
| 2-2. 누락 | 옵션 누락 / 사은품 X | 운영 |
| 2-3. 파손 | 배송 중 파손 | 운영 (택배사 클레임) |
| 2-4. 오배송 | 다른 제품 받음 | 운영 |
| 2-5. 포장 | 포장 부실 / 과포장 | 운영 + 디자이너 (패키징) |

## 3. 가격/결제

| 서브 | 정의 | 책임 |
|---|---|---|
| 3-1. 가격 비싸 | 비싸다 / 가성비 | 마케팅 (가치 전달) + 재무 |
| 3-2. 할인 / 쿠폰 | 쿠폰 안 됨 / 할인 적용 X | 마케팅 + 운영 |
| 3-3. 결제 오류 | 결제 실패 | 운영 + 데이터/개발 |
| 3-4. 환불 지연 | 환불 처리 지연 | 운영 (재무 협업) |
| 3-5. 배송비 | 무료배송 조건 | 운영 |

## 4. 사용성 / 가이드

| 서브 | 정의 | 책임 |
|---|---|---|
| 4-1. 착용 어려움 | 입히기 어렵 | 상품기획 + 마케팅 (가이드) |
| 4-2. 세탁 가이드 | 세탁법 모름 | 마케팅 (가이드) |
| 4-3. 사이즈 선택 | 어떤 거 사야 할지 | 마케팅 (가이드) + 상품기획 |
| 4-4. TOG 선택 | 등급 모름 | 마케팅 (TOG 가이드 콘텐츠) |
| 4-5. 보관 | 시즌 보관 | 마케팅 (가이드) |

## 5. 브랜드 / 기타

| 서브 | 정의 | 책임 |
|---|---|---|
| 5-1. 브랜드 인지 | 어디 브랜드? | 마케팅 (브랜드 노출) |
| 5-2. 환경 / 지속가능 | 친환경 인증 | 상품기획 + 브랜드실장 |
| 5-3. 신뢰 / 안전 | 안심 사용 | 상품기획 + 마케팅 |
| 5-4. 선물 | 선물용 패키징 | 디자이너 + 운영 |
| 5-5. 기타 | 위 5개 카테고리 외 | CS 분류 → 종합 |
