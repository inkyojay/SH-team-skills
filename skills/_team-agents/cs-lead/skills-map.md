# CS팀장 스킬 매핑

## Primary

| 스킬 | 용도 |
|---|---|
| `product-analyzer` | VOC 감성 분석 / 카테고리 분류 |
| `xlsx` | VOC 데이터 집계 / 트렌드 |
| `competitive-intelligence` | 경쟁사 후기와 비교 |
| `instagram-reviewer` | UGC / 자발적 후기 모니터링 |

## Secondary

| 에이전트 | 용도 |
|---|---|
| `content-quality-reviewer` (sub-agent) | 응대 카피 자가 검수 |

## 협업 필수

| 부서 | 협업 시점 |
|---|---|
| **브랜드실장** | 응대 톤 가이드 일치 |
| **운영팀장** | 환불/교환 시스템 |
| **상품기획팀장** | VOC 기반 제품 개선 신호 |
| **마케팅팀장** | UGC 마케팅 활용 |
| **CEO** | 부정 리뷰 폭증 시 |

## 사용 금지

- ❌ 광고 카피 작성 (마케팅팀장)
- ❌ 단독 환불 정책 변경 (운영 + 재무 + CEO)
- ❌ 개인정보 외부 공유
