## 5가지 핵심 워크플로우

### 워크플로우 1 — 신제품 출시 (8명 협업)

```
시장분석관      → 시장 신호 감지 (강도 강🔴)
   ↓
상품기획팀장    → 기회 카드 작성 + product-scout
   ↓
재무이사        → 수익 시뮬레이션 (보수/기본/낙관)
   ↓
브랜드실장      → 컨셉 brand DNA 자문
   ↓
CEO            → GO/HOLD/KILL 결재
   ↓ (GO)
운영팀장        → 발주 + 사양 정의
디자이너        → 패키징 + 제품 사진 (병렬)
   ↓
마케팅팀장      → 상세페이지 (pdp-builder) + 카피 (keyword-optimizer)
   ↓
브랜드실장      → 모든 출고물 검수 (PASS 받아야 출시)
   ↓
운영팀장        → Cafe24 / 스마트스토어 등록
마케팅팀장      → 광고 시작 (meta-ad-factory) + 인플루언서
CS팀장         → 후기 모니터링 (출시 4주)
```

총 소요 기간: 6~14주 (제품 카테고리 따라)

### 워크플로우 2 — 시즌 컬러 드롭 (5명)

```
시장분석관      → 시즌 트렌드 신호
   ↓
브랜드실장      → 크리에이티브 brief 작성 (12 섹션)
   ├─ 추천 컬러 (Sage / Soft Apricot 등)
   └─ 무드 (Garden / Dawn 등)
   ↓
디자이너        → 시즌 비주얼 제작
마케팅팀장      → 콘텐츠 캘린더 + 광고 (meta-ad-factory)
   ↓
브랜드실장      → 검수
   ↓
운영팀장        → 자사몰 메인 배너 / 카테고리 페이지
```

총 소요 기간: 3~4주

### 워크플로우 3 — 광고 캠페인 (4명)

```
마케팅팀장      → 캠페인 의도 + 채널
   ↓
시장분석관      → 키워드 / 시즌 트렌드
   ↓
디자이너        → 시안 21종 (meta-ad-factory)
   ↓
브랜드실장      → 검수 (모두 PASS)
   ↓
마케팅팀장      → 광고 발행 + 일일 모니터링
재무이사        → 주간 ROAS 검증
   ↓
재무이사        → 임계치 위반 시 일시정지 권고
```

총 소요 기간: 2~3주 (분기 캠페인) / 1주 (단일)

### 워크플로우 4 — 부정 리뷰 대응 (3명)

```
CS팀장         → 부정 리뷰 감지 (24시간 이내)
   ├─ 1건 → 즉시 회신
   └─ 5건+ → 위기 신호
   ↓
운영팀장        → 환불/교환 시스템 (해당되면)
   ↓
CS팀장         → 회복 응대 + 사은품 발송
   ↓ (5건+)
CEO            → 위기 대응 회의 소집
브랜드실장      → 응대 카피 검수 / 브랜드 위기 평가
   ↓
CS팀장         → 주간 VOC 트렌드에 패턴 정리
상품기획팀장    → 제품 개선 신호로 검토
```

총 소요 기간: 24h ~ 4주 (회복까지)

### 워크플로우 5 — 분기 전략 리뷰 (5명)

```
시장분석관      → 분기 시장 리포트
재무이사        → 분기 P&L
모든 팀장        → 분기 OKR 달성률
   ↓
전략실장        → 다음 분기 OKR 초안 + 자원 배분 시나리오
   ↓
CEO            → 분기 전략 리뷰 회의 (90분)
   ├─ 지난 분기 회고
   ├─ 시장 변화 vs 가설
   ├─ 다음 분기 OKR 결정
   └─ 자원 배분 결정
   ↓
모든 팀장        → 다음 분기 액션 플랜 작성
```

총 소요 기간: 1주 (회의 + 후속)

## 페이퍼클립 등록 가이드

각 에이전트 폴더의 다음 파일을 페이퍼클립에 첨부:

1. `PROFILE.md` — 페르소나 + 책임 + 권한 + 트리거
2. `skills-map.md` — 스킬 카탈로그
3. `cron.md` — 주기적 작업 (수동 등록)
4. `guides/*.md` — 역할별 가이드

또는 Desktop 배포본의 `00_통합본*.md` 단일 파일을 사용.
