# 지원사업팀장 스킬 매핑

## Primary

| 스킬 | 용도 |
|---|---|
| `bizinfo-api` (anthropic-skills) | 기업마당 API 공고 검색 — **핵심** |
| `pdf` | 사업계획서 작성 / 편집 |
| `docx` | Word 제안서 |
| `hwpx` | 한글 문서 (정부 양식) |
| `pptx` | 발표 자료 |
| `xlsx` | 예산 계획서 |

## Secondary

| 스킬 | 용도 |
|---|---|
| `pencil` MCP | 디자인 첨부 자료 |
| `internal-comms` (anthropic-skills) | 사내 보고 양식 |

## 협업 필수

| 부서 | 협업 시점 |
|---|---|
| **CEO** | 모든 신청서 최종 결재 |
| **재무이사** | 예산 계획 / 매출 데이터 |
| **상품기획팀장** | 제품 기술 정보 (R&D 사업) |
| **해외전략팀장** | 수출 지원사업 |
| **데이터/개발팀장** | 사업자 등록 정보 / 자격 데이터 |

## 사용 금지

- ❌ 자격 미달 사업에 시간 낭비
- ❌ 모든 신청서를 다 신청 (선택과 집중)
- ❌ CEO 결재 없이 제출
