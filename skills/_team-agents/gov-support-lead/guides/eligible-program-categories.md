## 적합도 판정 (S/A/B/C)

| 등급 | 기준 | 액션 |
|---|---|---|
| **S** | 사업 핏 100% / 선정 가능성 높음 / ROI 큼 | 즉시 신청 준비 |
| **A** | 적합 / 약간의 가공 필요 | 우선순위 |
| **B** | 부분 적합 / 신청 가능 | 시간 여유 시 |
| **C** | 한계 적합 / 선정 가능성 낮음 | 후순위 또는 패스 |

## 우선순위 룰

1. 마감 임박 + S/A 등급 = 최우선
2. 같은 등급이면 지원 금액 큰 것
