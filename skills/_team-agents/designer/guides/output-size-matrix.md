```

예:
~/Desktop/team-skills/이미지/abc-blanket/hero-1080x1080.png
~/Desktop/team-skills/이미지/abc-blanket/reels-9x16.png
```

## 흔한 함정

1. **메타 릴스 세이프존 무시** — 텍스트가 잘림
2. **모바일 미고려** — 자사몰 트래픽 80%+ 모바일
3. **해상도 부족** — 1080px 미만 X
4. **압축 과다** — JPEG 80% 이하 X
5. **컬러 프로파일 불일치** — sRGB 통일 (CMYK는 인쇄용만)
