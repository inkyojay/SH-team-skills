# 국가별 베이비 시장 가이드 (1차 압축)

## 우선순위 4국

### 🇯🇵 일본 (1순위 후보)
- **시장 규모**: 베이비 슬립 카테고리 약 $XX (확인 필요)
- **타겟**: 30대 첫째맘 + 출산선물 수요 큼
- **트렌드 키워드**: ナイトウェア (나이트웨어), スリープバッグ (슬립백), おくるみ (오쿠루미 = 스와들)
- **주요 채널**: 楽天 (라쿠텐), Amazon JP, 인스타
- **현지 경쟁**: 西松屋, アカチャンホンポ, Combi
- **장점 (우리 핏)**: 한국 디자인 선호 / 수면 솔루션 컨셉 잘 받아들임 / 프리미엄 출산선물 시장 큼
- **리스크**: 식품의약품 안전 인증 (PSE / 베이비용품 안전), 일본어 현지화 비용
- **진출 단계**: KOTRA 수출 바우처 → 라쿠텐 입점 → 자사몰 일본어판 → 인스타 일본 마케팅

### 🇺🇸 미국 (2순위 후보)
- **시장 규모**: 가장 큰 베이비 슬립 시장 ($XX BN)
- **타겟**: 다양 — 최우선은 SNS 활동 활발한 첫째맘
- **트렌드 키워드**: sleep sack, swaddle, baby sleep solution, TOG bedding
- **주요 채널**: Amazon, Buy Buy Baby, 자사몰, Etsy
- **현지 경쟁**: Kyte Baby (강함), Halo Sleep, Aden+Anais
- **장점**: 큰 시장 / TOG 시스템 이미 친숙 (ergoPouch 영향)
- **리스크**: 강한 경쟁 / Amazon FBA 비용 / CPSC 안전 인증 / 마케팅 비용 큼
- **진출 단계**: Amazon FBA + 인스타 미국 광고 → 자사몰 영문판 → 인플루언서 (모마미 영역)

### 🇨🇳 중국 (3순위)
- **시장 규모**: 매우 큼이지만 진입 장벽 높음
- **타겟**: 1선 도시 30대 엄마
- **트렌드 키워드**: 婴儿睡袋, 婴儿襁褓, 韩国婴儿用品
- **주요 채널**: 天猫国际 (티몰 글로벌), 小红书 (샤오홍슈), 抖音 (도우인)
- **현지 경쟁**: 다수 + 카피 위험 큼
- **장점**: 한국 베이비 브랜드 프리미엄 인식
- **리스크**: 카피 / 인증 비용 / 결제 / 물류 / 정책 변동
- **진출 단계**: 신중 검토. 우선 천천히 / 1선 도시 보세 채널만

### 🇸🇬 동남아 / 싱가포르 (4순위, 장기)
- **시장 규모**: 작지만 프리미엄 여지
- **타겟**: 영어 환경 + 프리미엄 수요
- **장점**: 영어 OK / 한국 트렌드 선호
- **리스크**: 시장 규모 작음
