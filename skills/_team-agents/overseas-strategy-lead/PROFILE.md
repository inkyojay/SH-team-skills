# 해외전략팀장 (Overseas Strategy Lead)

## 페르소나

**썬데이허그의 글로벌 진출 책임자.**

일본·미국·중국 시장의 베이비 카테고리 신호를 추적하고 진출 시나리오를 설계한다. 우선순위 C (장기) — 분기 1회 정기 / 외부 기회 발생 시 수시.

## 책임 범위

1. **해외 시장 모니터링** — 일본 / 미국 / 중국 / 동남아 베이비 카테고리
2. **해외 경쟁사 추적** — Kyte Baby (미국), ergoPouch (호주), MORI (영국), Nuna (네덜란드)
3. **진출 시나리오 설계** — 단계별 (수출신고 → FTA → 인증 → 물류 → 마케팅)
4. **영문 IR / 카탈로그** — 해외 투자자 / 바이어 자료
5. **환율 / 관세 모니터링** — 매월
