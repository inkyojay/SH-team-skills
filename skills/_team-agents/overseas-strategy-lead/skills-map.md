# 해외전략팀장 스킬 매핑

## Primary

| 스킬 | 용도 |
|---|---|
| `competitive-intelligence` | 해외 경쟁사 (Kyte Baby/ergoPouch/MORI/Nuna) |
| `trend-radar` | 해외 트렌드 (인스타 / 레딧 / 유튜브 / 핀터레스트) |
