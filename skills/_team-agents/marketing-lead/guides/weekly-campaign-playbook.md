## 콘텐츠 3 Pillars 비율

브랜드 가이드 7번 콘텐츠 전략 따름:

| Pillar | 정의 | 표준 비율 | 시즌 가중 |
|---|---|---|---|
| **1. 수면 사이언스** | TOG / 월령별 / 온도별 가이드 | 30% | 비수기 +10% |
| **2. 시즌 비주얼** | 시즌 컬러 드롭 / 룩북 | 40% | 시즌 +20% |
| **3. 리얼 후기** | UGC / 사용 전후 / 슬립로그 | 30% | 변동 X |

→ 분기마다 비율 조정. 시즌 컬러 드롭 분기는 Pillar 2 가중.

## 발행 흐름 (브랜드실장 검수 필수)

```
1. 콘텐츠 기획 (마케팅팀장)
   ↓
2. 카피 작성 (마케팅팀장 + keyword-optimizer SEO 카피)
   ↓
3. 디자인 (디자이너 + meta-ad-factory / card-news / 디자이너 수작업)
   ↓
4. 사진 톤 통일 (tone-match-local — 디폴트 무드 또는 시즌 무드)
   ↓
5. 브랜드실장 검수 ★ 필수
   ├─ PASS → 발행
   ├─ WARN → 수정 후 발행
   └─ FAIL → 재작업 (구체 위반 항목 + 수정안 받음)
   ↓
6. 발행 (인스타 / 블로그 / 광고 매니저 / 카페24 등)
   ↓
7. 성과 추적 (다음날 cron으로 자동)
```

## 신규 캠페인 SOP (시즌 컬러 드롭 등)

1. **브랜드실장에게 brief 요청** — `creative-brief-template.md` 작성
2. **brief 받기**: 컬러 / 무드 / 톤 / 스킬 체인 가이드 포함
3. **스킬 체인 실행** (brief 9번 항목 따름):
   ```
   keyword-optimizer → tone-match-local → pdp-builder → meta-ad-factory → marketing-planner
   ```
4. **검수 → 발행**

## 광고 운영 룰

- 신규 광고: 최소 3 변형 동시 발행 (A/B/C 테스트)
- 7일 후 ROAS 분석 → 하위 1개 일시정지, 상위 2개 예산 증액
- 임계치 (재무이사 정의) 미달 시 즉시 일시정지
- 분기 1회 메타 21개 풀 빌드 (`meta-ad-factory`)

## 흔한 함정

1. **검수 건너뛰고 발행** — 절대 X
2. **3 Pillars 비율 한쪽 쏠림** — 매월 점검
3. **광고만 키우고 콘텐츠 빠짐** — 광고는 가속기, 콘텐츠는 기반
4. **체험단 효과 측정 X** — 핸들별 매출 기여 추적
5. **시즌 캠페인을 너무 늦게 준비** — 4주 전부터 brief
