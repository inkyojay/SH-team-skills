# 인플루언서/체험단 협업 SOP

## 발굴 기준 (SundayHug 운영)

브랜드 가이드 + instagram-reviewer 메모 따름:

| 항목 | 기준 |
|---|---|
| 팔로워 | 2,000~50,000 (마이크로 ~ 미드티어) |
| 자녀 연령 | 0~24개월 (정확히 일치 우선) |
| 사진 감도 | **최우선** — 무드형 피드, 자연광, 여백 |
| 촬영 퀄리티 | DSLR 또는 미러리스 / 자연광 활용 |
| 톤 | 우리 브랜드("현명한 친구") 와 충돌 없는지 |
| 진정성 | 광고/체험단 빈도 너무 높으면 제외 |

## 제외 기준 (Hard Stop)

- ❌ 브랜드/스토어 계정 (개인 X)
- ❌ 정보성 계정 (쇼핑 큐레이션 X)
- ❌ 자극적 톤 (`!!!`, "대박", "꿀템" 류)
- ❌ 직접 광고 게시물 비중 > 30%
- ❌ 경쟁 베이비 슬립 브랜드 정기 협업

## 발굴 절차

```
1. instagram-reviewer 자동 실행 (격주 화 14:11 cron)
   - 해시태그 기반: #썬데이허그 / #슬립백추천 / #육아맘 / #뉴본맘 등
   - 5명 후보 + S~D 등급
   ↓
2. 마케팅팀장 1차 검토
   - 사진 감도 / 톤 적합성
   - 자녀 연령 정확
   ↓
3. 브랜드실장 검수 (필수)
   - 우리 브랜드와 어울리는지 최종 판단
   ↓
4. 컨택 (DM)
```

```

@__님의 피드에서 자연스럽고 따뜻한 일상이 느껴져서 인사드립니다.

저희는 한국 아기들의 깊은 잠을 위한 슬립 솔루션 브랜드 썬데이허그예요.
@__님의 피드 톤과 저희 브랜드의 무드가 잘 어울릴 것 같아 체험을 제안드리고 싶어요.

자세한 내용 안내드려도 될까요?

— 썬데이허그 마케팅팀 드림
```

## 체험 제공 패키지

| 패키지 | 발송 | 요청사항 |
|---|---|---|
| 베이직 | 주력 SKU 1종 | 피드 1개 + 스토리 1개 |
| 시그니처 | 시즌 컬렉션 1세트 | 피드 2개 (1주 간격) + 스토리 + 릴스 1개 |
| 프리미엄 | 시즌 컬러 풀 라인업 | 룩북 캠페인 협업 (4주) + 별도 컨트랙트 |

> 모든 게시물은 발행 전 브랜드실장 1차 검수.

## 동봉물

(브랜드 가이드 6번 패키징 동봉물 룰 따름)
- 수면 가이드 카드 (TOG 착장 가이드)
- 손글씨 감사 메시지 카드
- 인스타 해시태그 안내 (`#썬데이허그 #오늘밤도잘자`)
- 포토 리뷰 이벤트 안내

## 효과 측정 (4주 후)

| 지표 | 측정 방법 |
|---|---|
| **도달** | 인스타 인사이트 (인플루언서 보고) |
| **유입** | 자사몰 referral (UTM) |
| **매출 기여** | 첫 7일 자사몰 매출 + 유입 매출 |
| **UGC 생성** | 해시태그 검색 / 메인 피드 재게시 |

## 흔한 함정

1. **팔로워 수 우선** — 매칭 점수가 더 중요 (마이크로 인플루언서 ROAS ↑)
2. **대량 컨택** — 핀포인트 컨택이 답변률 높음
3. **검수 건너뜀** — 인플루언서 게시물도 우리 브랜드. 검수 필수
4. **효과 측정 X** — 4주 후 안 보면 다음 발굴 기준 못 정함
5. **체험 후 관계 끊김** — 좋은 인플루언서는 분기 1회 재방문 / 시즌 협업
