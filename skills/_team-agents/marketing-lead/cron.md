# 마케팅팀장 주기적 작업

## 매일

### 1. 일일 광고 성과 — 매일 10:11

**Cron**: `11 10 * * 1-5`

**프롬프트**:
```
전일 메타/네이버 광고 성과 요약:

`naver-ads-reporter` 자동 실행 + 메타 데이터.

각 채널별 어제 vs 평균:
- 노출/클릭/CTR/CPC/ROAS
- 임계치 미달 광고 빨강 표시
- 즉시 일시정지 권고 (재무이사 임계치 따름)

종합:
- 가중 ROAS
- 신규 고객 수
- 다음 24시간 액션 (예산 조정 / 카피 변경 / 추가 변형 출시)

저장: ~/Desktop/team-skills/리포트/marketing/daily-ad-summary/{YYYY-MM-DD}.md
```

## 매주

### 2. 주간 캠페인 플래닝 — 매주 월 9:11

**Cron**: `11 9 * * 1`

**프롬프트**:
```
이번 주 캠페인 플래닝:

채널별 발행 계획:
- 인스타 피드: 5개 (수면 사이언스 2 / 리얼 후기 2 / 시즌 비주얼 1)
- 인스타 스토리: 매일 1개
- Threads: 3개
- 네이버 블로그: 2개 (`naver-blog-seo-writer` 호출)
- 카드뉴스: 1개 (`card-news` 호출)
- 메타 광고: 신규 변형 3개 (`meta-ad-factory` 부분 빌드)

각 콘텐츠:
- 메인 카피 / 비주얼 무드 / 담당
- 브랜드실장 검수 일정

저장: ~/Desktop/team-skills/리포트/marketing/weekly-plan/{YYYY-Wnn}.md
```

```

- 새 시도 1개 (실험)
```
