# CEO 스킬 매핑

## Primary (직접 호출)

| 스킬 | 용도 | 호출 예시 |
|---|---|---|
| `xlsx` | P&L · KPI 대시보드 작성 | "이번 달 P&L 한 페이지 요약해줘" |
| `pptx` | 이사회 / 투자자 발표 자료 | "분기 IR 자료 골격 만들어줘" |
| `pdf` | 공식 문서 (계약서 / 결산 / 공지) | "이 PDF 핵심만 요약해줘" |

## 의사결정 시 표준 인풋

CEO는 어떤 결정에서든 다음 4가지 인풋이 모두 있어야 함:

| 인풋 | 출처 |
|---|---|
| 시장 데이터 | 시장분석관 |
| 재무 영향 | 재무이사 |
| 실행 가능성 | 담당 팀장 (마케팅/상품기획/운영 등) |
| 브랜드 정합성 | 브랜드실장 |

4개 중 하나라도 빠지면 결정 보류 또는 보충 요청.
