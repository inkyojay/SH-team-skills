# 분기 전략 리뷰 (Quarterly Strategy Review)

> 분기 첫 영업일에 cron 자동 발동. 12장 pptx + 사회자 토킹 포인트.

## 어젠다 (90분)

| 시간 | 섹션 | 진행 |
|---|---|---|
| 0~5 | 지난 분기 한 줄 회고 | CEO |
| 5~20 | 지난 분기 OKR 달성률 | 전략실장 |
| 20~35 | 시장 변화 vs 가설 검증 | 시장분석관 |
| 35~50 | 재무 성과 vs 목표 | 재무이사 |
| 50~65 | 부서별 핵심 학습 | 각 팀장 (각 2분) |
| 65~80 | 다음 분기 우선순위 후보 3개 | 전략실장 (CEO 결정) |
| 80~90 | Q&A + 결정 사항 정리 | CEO |

## pptx 12장 구성

```
1. Cover (분기 / 일자)
2. 지난 분기 한 줄 평가 (CEO)
3. 지난 분기 OKR 달성률 표
4. 핵심 KPI 트렌드 (4개)
5. 시장 변화 (시장분석관 — 무엇이 변했나)
6. 가설 검증 결과 (가정 vs 실제)
7. 재무 P&L 분기 vs 목표
8. 채널별 ROAS / CAC / Payback
9. 부서별 핵심 학습 (1장에 부서당 1줄)
10. 다음 분기 우선순위 후보 3개 + 베팅 근거
11. 자원 배분 시나리오 (마케팅 vs 상품기획 vs 운영 비중)
12. 다음 분기 OKR 초안 (4축: 매출/브랜드/제품/조직)
```

## OKR 4축 표준

```
Objective: (정성적, 영감 있는 한 줄)

Key Results: (정량적, 측정 가능, 야심적)
- KR1: ...
- KR2: ...
- KR3: ...
```

| 축 | 예시 (분기 단위) |
|---|---|
| **매출** | "분기 매출 KRW X.X억 / 자사몰 비중 40%+" |
| **브랜드** | "브랜드 검색량 +30% / NPS 60+" |
| **제품** | "신제품 2종 출시 / 라인업 SKU 30개 도달" |
| **조직** | "스킬 카탈로그 25개 / 자동화 cron 20개" |

## 결정 사항 양식

회의 끝에 CEO가 결정 사항을 1페이지로 즉시 기록:

```markdown
# Q{n} {YYYY} Strategic Decisions

## 결정된 OKR (4축)
- Objective: ...
- KRs: ...

## 자원 배분
- 마케팅: XX%
- 상품기획: XX%
- 운영: XX%
- 기타: XX%

## 우선순위 (Top 3)
1. ... (담당: __)
2. ... (담당: __)
3. ... (담당: __)

## 안 하기로 한 결정 (no-go log 추가)
- ... (사유: __)

## 다음 분기 검토 트리거
- "~ 지표가 ~ 미달이면 자원 배분 재검토"
```

저장: `~/Desktop/team-skills/리포트/ceo/quarterly-{YYYY-Qn}/decisions.md`

## 함정

1. **너무 많은 OKR** — 분기당 KR 9~12개가 적정. 그 이상이면 우선순위 상실
2. **지난 분기 회고 부족** — 실패에서 배운 것 명시 안 하면 같은 실수 반복
3. **부서별 발표가 자기 자랑** — 사실/숫자/학습만, 미사여구 X
4. **다음 분기 우선순위가 "다 하자"** — 항상 안 할 것을 명시
