# CEO 의사결정 프레임워크

## 핵심 원칙

> **모든 결정은 Type 1 (되돌리기 어려움) 또는 Type 2 (되돌릴 수 있음)로 분류한다.**
> Type 1은 신중하게 — 데이터 없으면 보류. Type 2는 빠르게 — 작게 시도하고 학습.

## Type 분류

| Type | 정의 | 예시 | 결정 방식 |
|---|---|---|---|
| **Type 1** | 되돌리기 어렵거나 비용이 큰 결정 | 브랜드 리포지셔닝 / 큰 자본 투자 / 핵심 제품 단종 / 해외 진출 | 시간을 충분히 / 4개 인풋 모두 필요 |
| **Type 2** | 빠르게 되돌릴 수 있는 결정 | 광고 카피 변경 / 작은 프로모션 / 시즌 컬러 1개 추가 | 빠르게 / 작게 시도 / 학습 |

## 4개 인풋 (Type 1 결정 시 필수)

CEO는 어떤 Type 1 결정에서든 다음 4개 인풋이 모두 있어야 한다:

| # | 인풋 | 출처 | 빠진다면 |
|---|---|---|---|
| 1 | **시장 데이터** | 시장분석관 | "이게 진짜 시장이 원하는 건가?" 검증 부족 |
| 2 | **재무 영향** | 재무이사 | 수익성/현금흐름 모르고 결정 |
| 3 | **실행 가능성** | 담당 팀장 | 우리가 진짜 할 수 있는지 모름 |
| 4 | **브랜드 정합성** | 브랜드실장 | 단기 이익이 장기 브랜드를 죽일 수 있음 |

→ 4개 중 하나라도 빠지면 **결정 보류** 또는 **보충 요청**.

## RICE 스코어링 (우선순위 정렬용)

여러 옵션 중 하나를 골라야 할 때:

```
RICE Score = (Reach × Impact × Confidence) / Effort

Reach:      얼마나 많은 고객/매출에 영향? (1~10)
Impact:     영향이 얼마나 큰가? (0.25 / 0.5 / 1 / 2 / 3)
Confidence: 우리 추정에 대한 자신감? (0.5 / 0.8 / 1.0)
Effort:     얼마나 많은 시간/자원? (1~10, 사람 X 주)
```

스프레드시트는 `xlsx` 스킬로 빠르게 작성: "RICE 스코어 시트 만들어줘"

## 영향도 × 긴급도 매트릭스

```
            높은 긴급도        낮은 긴급도
높은 영향   [즉시 결정]        [Type 1 — 신중]
            ─────────────       ─────────────
낮은 영향   [위임 / Type 2]    [무시 / 백로그]
```

매주 월요일 보고 종합 시 모든 안건을 이 4분면에 배치.

## "안 하기로 한 결정" 기록

CEO 책상 위 가장 중요한 문서: **반대 결정 로그**

`~/Desktop/team-skills/리포트/ceo/decisions/no-go-log.md` — 거절한 사업/제품/협업 + 사유 기록.

> 안 한 결정 = 시간을 번 결정. 6개월 뒤 같은 안건이 또 오면 사유가 여전히 유효한지 점검.

## 결정 1페이지 양식 (Decision Memo)

매 Type 1 결정마다 다음 1페이지 작성:

```markdown
# Decision: [결정 제목]
Date: YYYY-MM-DD  | Type: 1 (되돌리기 어려움) | Status: Decided / Deferred / Vetoed

## 1. 무엇을 결정하는가
한 문장.

## 2. 왜 지금
시장/내부/위기 어떤 것이 트리거인가.

## 3. 옵션 (3개 이상)
- A: ...
- B: ...
- C: 아무것도 안 함 (always include)

## 4. 4개 인풋 (필수)
- 시장 데이터 (시장분석관): ...
- 재무 영향 (재무이사): ...
- 실행 가능성 (담당 팀장: __): ...
- 브랜드 정합성 (브랜드실장): ...

## 5. 선택 + 사유
선택한 옵션과 핵심 근거 3줄.

## 6. 가설과 검증 시점
"~할 것이라 가정. 3개월 뒤 ~ 지표로 검증."

## 7. 되돌릴 트리거
"~ 되면 결정 재검토 또는 철회."
```

저장: `~/Desktop/team-skills/리포트/ceo/decisions/{YYYY-MM-DD}_{slug}.md`

## 위임 vs 직접 결정 룰

| 상황 | 결정자 |
|---|---|
| 상시 광고 운영, 일일 카피 | 마케팅팀장 |
| 새 광고 캠페인 컨셉 (분기 단위 큰 캠페인) | 마케팅팀장 + 브랜드실장 (CEO는 결재만) |
| 신제품 GO/HOLD/KILL | CEO (상품기획팀장 제안) |
| 브랜드 리포지셔닝 | CEO + 전략실장 + 브랜드실장 |
| 해외 진출 GO/NO-GO | CEO (해외전략팀장 제안 + 재무이사 검증) |
| 재고 발주 | 운영팀장 (예산 한도 내) |
| 가격 변경 | 재무이사 + 마케팅팀장 (CEO 결재) |
| 채용 / 조직 변경 | CEO |
| 위기 대응 (부정 리뷰 폭증, 사고) | CEO 즉시 |

## 자주 빠지는 함정

1. **데이터 안 보고 직관** — 직관도 가설로 명시한다
2. **누구나 좋아하는 답** — Type 1 결정은 보통 누군가 반대한다. 모두 좋아하면 더 큰 그림 놓친 것
3. **분기 너무 많은 결정** — 한 분기에 Type 1 결정은 3~5개로 제한
4. **"빨리 결정해야 한다" 압박** — Type 1이면 24시간 의도적 지연도 OK
