# CEO 주기적 작업 (Cron Schedule)

> 페이퍼클립 시스템에서 수동 등록하는 자동 트리거 목록.
> Cron 표기는 5필드 표준 (`m h dom mon dow`), 시각은 한국 시간 기준.

## 매일

(없음 — CEO는 일 단위 자동화 없음. 위기 발생 시 부서장이 직접 호출)

## 매주

### 1. 주간 부서별 보고 종합 — 매주 월 9:03

**Cron**: `3 9 * * 1`

**프롬프트**:
```
이번 주 임원회의 어젠다 작성:

각 팀장 에이전트(시장분석관/재무이사/마케팅팀장/브랜드실장/상품기획팀장/운영팀장/CS팀장/지원사업팀장/데이터팀장)
의 지난주 보고를 종합하여 1페이지 요약 출력. 형식:

1. **이번 주 핵심 KPI** (매출/ROAS/NPS/재고)
2. **부서별 헤드라인** (각 1줄)
3. **위기 신호** (있다면 빨강)
4. **오늘 결정 필요 사항** (TOP 3)
5. **다음 주 우선순위**

출력은 ~/Desktop/team-skills/리포트/ceo/{YYYY-MM-DD}_weekly-summary.md
```

## 매월

### 2. 월간 KPI 대시보드 — 매월 1일 9:03

**Cron**: `3 9 1 * *`

**프롬프트**:
```
지난 달 KPI 대시보드 업데이트:

- 매출 / 영업이익 / 마케팅 ROAS / NPS — 4개 지표 트렌드 (지난 12개월)
- 채널별 매출 비중 (자사몰 vs 스마트스토어 vs 쿠팡 vs 카카오)
- 신제품 출시 현황 (계획 대비 진행)
- 재고 회전율 / 품절 발생 횟수
- 브랜드 가이드 위반 적발 건수 (브랜드실장 보고 종합)

출력: xlsx로 dashboard 시트 + md로 1페이지 요약.
저장: ~/Desktop/team-skills/리포트/ceo/{YYYY-MM}_monthly-kpi.xlsx + .md
```

## 매분기

### 3. 분기 전략 리뷰 어젠다 — 분기 첫 영업일 10:03

**Cron**: `3 10 1 1,4,7,10 *` (1/4/7/10월 1일)

**프롬프트**:
```
분기 전략 리뷰 회의 어젠다 작성:

- 지난 분기 OKR 달성률 (전략실장 데이터)
- 시장 변화 vs 가설 검증 (시장분석관 데이터)
- 다음 분기 우선순위 후보 3개
- 자원 배분 시나리오 (마케팅 vs 상품기획 vs 운영)
- 외부 위험/기회 (해외전략팀장 입력)

출력: pptx 12장 발표자료 + 사회자용 토킹 포인트 md.
저장: ~/Desktop/team-skills/리포트/ceo/quarterly-{YYYY-Qn}/
```

## 매년

### 4. 연말 종합 + 차년도 비전 — 12월 둘째 주 월 14:03

**Cron**: `3 14 8-14 12 1` (12월 둘째 월요일)

**프롬프트**:
```
연말 종합 자료 + 차년도 비전 초안:

- 올해 OKR 최종 달성률
- 매출/이익 연간 vs 작년 vs 계획
- 핵심 학습 (잘된 것 / 안 된 것 / 의외였던 것)
- 차년도 비전 후보 3개 (각 베팅 근거 + 리스크)
- 차년도 분기별 1차 OKR 초안

출력: pptx (이사회 발표용) + 1페이지 비전 md.
저장: ~/Desktop/team-skills/리포트/ceo/annual-{YYYY}/
```

## 위기 대응 트리거 (자동 발동, cron 아님)

다음 신호 감지 시 CEO에게 즉시 알림:

| 신호 | 출처 | 발동 임계치 |
|---|---|---|
| 부정 리뷰 폭증 | CS팀장 | 일일 부정 리뷰 ≥5건 |
| 광고 ROAS 급락 | 재무이사 | 채널 ROAS WoW -20% |
| 재고 사고 | 운영팀장 | 메인 SKU 품절 발생 |
| 브랜드 가이드 중대 위반 | 브랜드실장 | Critical 위반 외부 노출 |
| 경쟁사 직접 도전 | 시장분석관 | 동일 카테고리 경쟁사 가격 -30% 출시 |

## 페이퍼클립 등록 시 주의

- 매주 월 9:03 작업은 **각 팀장 에이전트가 일요일~월 새벽에 자기 보고를 미리 끝낸 상태**여야 작동.
  → 팀장 cron 시간이 CEO cron보다 먼저 끝나도록 페이퍼클립에서 의존 관계 설정 필요.
- 한 번에 모든 cron을 켜면 부담 → 1번(주간)부터 활성화, 안정화 후 2/3/4번 추가 권장.
