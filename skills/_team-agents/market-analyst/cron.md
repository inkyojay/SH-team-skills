# 시장분석관 주기적 작업

## 매일

### 1. 일일 키워드 변화 알림 — 매일 9:13 (선택, 시즌 한정)

**Cron**: `13 9 * * 1-5` (평일만)

**프롬프트**:
```
어제 네이버 데이터랩 베이비 카테고리 TOP 100 키워드 중 ±20% 이상 변동 키워드 추출.
변동 사유 추정 (시즌 / 경쟁사 출시 / SNS 바이럴 / 뉴스 이슈 중) + 신호 강도(강/중/약).

5개 이상 발견 시에만 출력. 0~4개면 "특이사항 없음" 한 줄.
저장: ~/Desktop/team-skills/리포트/market-analyst/daily/{YYYY-MM-DD}.md
```

> ⚠️ 평소엔 비활성. 시즌 캠페인 직전 2주만 활성화 권장.

## 매주

### 2. 주간 트렌드 리포트 — 매주 월 8:07

**Cron**: `7 8 * * 1`

**프롬프트**:
```
지난 주(월~일) 베이비 카테고리 핵심 트렌드 리포트:

1. 네이버 데이터랩 — 검색량 ±10% 이상 변동 키워드 TOP 20
2. 신규 경쟁 키워드 출현 (이전 4주에 없던 새 키워드)
3. 인스타/유튜브/레딧 — 베이비 슬립 / 스와들 / 슬립백 멘션 변화
4. 시즌 트렌드 — 다음 분기 미리 보기 (`keyword-trend` 자동 실행)
5. 핵심 신호 3개 + 강도(강/중/약)
6. CEO/전략실장에게 전달할 요약 한 줄

저장: ~/Desktop/team-skills/리포트/market-analyst/weekly-trends/{YYYY-Wnn}.md
형식: md + Chart.js 트렌드 차트 임베드 (HTML 가능)
```
