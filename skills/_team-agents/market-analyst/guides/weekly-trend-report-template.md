[출처: 네이버 데이터랩 쇼핑 / YYYY-MM-DD~]

## 🆕 신규 출현 키워드 (지난 4주에 없던)

## 작성 팁

1. **숫자 + 해석** — 숫자만 나열 X, 매 표 다음 1줄로 의미 설명
2. **신호 강도 보수적** — 🔴 강은 신중히 표기 (적중률 직접 영향)
3. **출처 매번 명시** — 데이터 소스 + 시점
4. **차트 적극 활용** — Chart.js로 라인/바 차트 임베드 (HTML 옵션)
5. **분량 1페이지 + 차트 별첨** 원칙
