## 4개 추적 차원

각 경쟁사를 매주(격주)마다 다음 4개 차원으로 점검:

### 1. 제품 (Product)
- 신제품 출시 (지난 2주)
- 단종/소진 SKU
- 라인업 확장 시그널

### 2. 가격/프로모션 (Pricing)
- 가격 변동
- 시즌 할인 / 번들
- 무료 배송 / 사은품 정책

### 3. 콘텐츠 (Content)
- 인스타 게시물 빈도 / 도달 추정
- 캐러셀 / 릴스 톤 변화
- 인플루언서 협업 / 체험단

### 4. 검색 점유 (Search)
- 네이버 쇼핑 키워드 점유 변화
- 자사몰 검색 노출
- 블로그/카페 후기 빈도

## 우리에게 의미 (So What?)

매 모니터링마다 마지막에 **"So what for us?"** 1줄 명시:

- ✅ 위협 신호 → 즉시 액션
- ✅ 기회 신호 → 차별화 강화
- ✅ 학습 신호 → 우리 적용 가능한 패턴

## 비교 금지 원칙 (브랜드 가이드 V-04)

- ❌ 직접 비교/비하 콘텐츠 절대 금지
- ✅ 내부 분석 자료에만 비교 사용
- ✅ 외부 콘텐츠는 우리 가치만 강조
