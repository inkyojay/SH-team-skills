# 소비자 신호 레이더

## 핵심 시그널 3종

### 1. 검색량 급증 (네이버 데이터랩)
- 일일 ±20% / 주간 ±10% 이상 변동
- 시즌성 vs 진짜 신호 구분 (전년 동월 대비)

### 2. SNS 멘션 급증 (인스타 / 유튜브 / 레딧)
- 해시태그 빈도
- 멘션 sentiment (긍정 / 부정 / 중립)
- 인플루언서 채택

### 3. 카페/블로그 토픽 (네이버 카페 / 블로그)
- 맘카페 인기 토픽 (육아카페 / 베이비페어)
- 블로그 신규 포스트 빈도

## 시그널 → 액션 흐름

```
신호 감지 (자동 cron 또는 수동)
   ↓
신호 강도 판정 (강/중/약)
   ↓
   ├─ 🔴 강 → 즉시 CEO + 상품기획팀장 + 마케팅팀장 알림
   ├─ 🟡 중 → 2주 모니터링 후 재평가
   └─ 🟢 약 → 참고 기록만
```

## 신호 강도 판정 매트릭스

| 차원 | 강 | 중 | 약 |
|---|---|---|---|
| 검색량 변화 | +30%↑ | +10~30% | ±10% |
| 다중 채널 신호 | 3개 채널 동시 | 2개 채널 | 1개 채널 |
| 경쟁사 진입 | 동시 진입 | 1개 진입 | 없음 |
| 시즌성 보정 | 시즌 외 변동 | 시즌 약간 강화 | 시즌 패턴 일치 |

**최소 3개 차원 이상 일치할 때만 🔴 강 판정**.

## 자주 빠지는 함정

1. **노이즈를 신호로 착각** — 일회성 바이럴 (한 인플루언서) ≠ 카테고리 신호
2. **시즌성 무시** — 베이비 카테고리는 출산 트렌드/명절/계절 영향 큼. 전년 동기 대비 필수
3. **확증 편향** — "내가 보고 싶은 신호"만 강조 — 반대 가설도 같이 검증
4. **신호 강도 인플레** — 모든 게 🔴이면 아무것도 🔴이 아님 (분기당 강 신호 5건 이내)
