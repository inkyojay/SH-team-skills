# OKR 템플릿 (4축 표준)

## 기본 형식

```
Objective: (정성, 영감 있는 한 줄)

Key Results: (정량, 측정 가능, 야심적)
- KR1: (구체 수치 + 측정 방법)
- KR2:
- KR3:

가설: (왜 이 KR이 가능한가, 어떤 조건에서 달성되는가)

검증 시점: (분기말 / 매월 갱신)
```

## 4축 예시 (분기 단위)

### 1. 매출 (Revenue)
```
Objective: "한국 베이비 슬립 시장에서 가장 많이 검색되는 자사몰이 된다."

KRs:
- 분기 매출 KRW 6.0억 달성
- 자사몰 비중 40%+ (현재 32%)
- 신제품 매출 비중 20%+ (현재 8%)

가설: "TOG 시스템 콘텐츠 시리즈가 자사몰 검색 +50% 견인 (시장분석관 신호 강)"

검증: 매월 자사몰 검색량 / 신규 고객 / 신제품 매출
```

### 2. 브랜드 (Brand)
```
Objective: "프리미엄 베이비 수면 솔루션 브랜드로 인식된다."

KRs:
- NPS 60+ (현재 52)
- 브랜드 검색량 +30% (네이버)
- 인스타 도달 200K/월 (현재 130K)

가설: "시즌 컬러 드롭 + 수면 사이언스 콘텐츠 병행이 인지도 +30% 견인"

검증: NPS 매월 / 검색량 매월 / 인스타 인사이트 매주
```

### 3. 제품 (Product)
```
Objective: "수면 사이클 전 단계를 커버하는 라인업을 갖춘다."

KRs:
- 신제품 2종 출시 (슬립색 + 스와들)
- 라인업 SKU 30개 도달 (현재 24)
- TOG 0.3 / 1.0 / 2.5 / 3.5 4단계 모두 ≥ 2종

가설: "여름 슬립 카테고리 진공 → 0.3 TOG 신제품 시장성 강"

검증: 분기 출시 일정 / SKU 수 / TOG별 라인업
```

### 4. 조직 (Organization)
```
Objective: "스킬 시스템과 자동화로 인당 매출 2배."

KRs:
- 스킬 카탈로그 25개 도달 (현재 23)
- 자동화 cron 20개 가동
- 페이퍼클립 13명 에이전트 모두 안정 운영

가설: "자동화 도입 시 부서장 일주일 5시간 절감 → 전략 업무 비중 ↑"

검증: 카탈로그 수 / cron 가동률 / 부서장 시간 사용 주관 평가
```

## OKR 작성 룰

1. **Objective는 영감 있게, KR은 차갑게** — O는 동기부여, KR은 측정
2. **KR은 야심적으로** — 70% 달성이 "잘한 것" 수준 (Google 기준)
3. **3개 이내 KR** — 5개 이상은 우선순위 상실
4. **분기당 12개 KR 이내** (4 O × 3 KR) — 그 이상이면 집중 불가
5. **가설 명시** — "왜 가능한가"가 없으면 그냥 희망사항
6. **검증 시점 명시** — 매월 / 매주 / 분기말 중

## 흔한 함정

1. **모든 게 다 중요하다** — 진정한 우선순위는 1~2개
2. **활동 기반 KR** — "10편 콘텐츠 발행" (X) → "콘텐츠 통한 신규 고객 100명" (O)
3. **외부 의존 KR만** — "경쟁사가 망함" 같은 통제 불가 변수 X
4. **너무 쉬운 KR** — 100% 달성률 분기는 KR이 너무 쉬웠다는 신호
