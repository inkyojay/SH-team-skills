# 포지셔닝 맵 (썬데이허그)

> 브랜드 가이드 10번 포지셔닝 맵을 전략 관점에서 활용.

## SundayHug 포지셔닝 (현재)

| 차원 | 우리 위치 | 설명 |
|---|---|---|
| **핵심 전략** | 수면 솔루션 + 감성 컬러 + 프리미엄 선물 | 3축 융합 |
| **타겟** | 30대 첫째맘 (정보+감성 교차) | 정보형/감성형 모두 |
| **가격대** | 3만~7만원 | 국내 프리미엄 (수입 브랜드보다 낮음) |
| **차별점** | "한국 아기 수면 전문가" | TOG 한국형 |

## 경쟁 포지셔닝 비교

| 브랜드 | 핵심 전략 | 타겟 | 가격대 | 차별점 |
|---|---|---|---|---|
| **ergoPouch** | 수면 과학 + TOG 가이드 | 정보형 엄마 | $40~60 | "Sleep Made Simple" |

| **제니티브** | 미니멀 디자인 | 디자인 감도 | 4만~10만 | 한국 미니멀 |
| **쉐베베** | 패브릭 무드 | 감성형 엄마 | 3만~6만 | 국산 베이비 패브릭 |

## 2축 포지셔닝 맵 (예시)

```
     높은 가격
        ▲
        │
  Kyte  │
   •    │
   MORI │
    •   │
        │      • SundayHug ← 우리
   ergo │
   •    │
        │
        │ • 쉐베베
        │
  ──────┼──────────►
 정보형 │  감성형
        │ • 제니티브
```

→ 우리는 **정보형/감성형 교차 + 프리미엄 중간**이라는 독특한 위치.

## 분기 포지셔닝 점검 룰

매 분기 시작 시 다음 질문에 답:

1. **시장 인식과 우리 의도가 일치하는가?**
   - 네이버 후기 / 인스타 멘션 톤 → 우리가 의도한 포지션과 같은가?
2. **경쟁사 이동 감지**
   - ergoPouch가 더 감성형으로? Kyte가 한국 진출?
3. **포지션 강화 vs 이동**
   - 우리 위치 강화할까, 빈 영역으로 이동할까?
4. **포지션 변경 비용**
   - 변경 시 브랜드 리포지셔닝 비용 (Type 1 결정)

## 전략 결정 시 활용

신제품 / 가격 변경 / 캠페인 컨셉 결정 시 다음 체크:

- 이 결정이 우리 포지션을 **강화**하는가?
- 만약 **이동**한다면, 이동의 의도와 비용이 명확한가?
- 경쟁사가 이 결정을 보고 어떻게 반응할 가능성이 큰가?
