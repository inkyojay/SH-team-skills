# 신제품 워크플로우 (Discovery → Launch)

## 4단계

```
1. Discovery (기회 발굴)        — 시장분석관 / product-scout
2. Feasibility (타당성 검증)    — 재무이사 / 브랜드실장 / 시장분석관
3. Build (제품 만들기)          — 운영팀장 / 디자이너 / 상세페이지
4. Launch (출시)                — 마케팅팀장 / 브랜드실장 검수
```

## Stage 1: Discovery (1~2주)

**입력**:
- 시장분석관 주간 트렌드 리포트
- `product-scout` 월간 기회 카드
- 경쟁사 신제품 모니터링
- CS팀장 VOC ("이런 제품 있으면 좋겠어요")

**산출**:
```markdown
# Opportunity Card: [제품명]

- 카테고리:
- 시장 신호 강도: 🔴/🟡/🟢
- 예상 시장 규모:
- 경쟁 강도:
- 우리 핏:
```

**결정**: 다음 단계로? Y/N

## Stage 2: Feasibility (2~3주)

**병렬 검증**:

| 검증 | 담당 | 산출 |
|---|---|---|
| 재무 시뮬레이션 | 재무이사 | 보수/기본/낙관 3 시나리오 |
| 브랜드 정합 | 브랜드실장 | 3축 매핑 + 톤 적합성 |
| 시장 신호 추가 검증 | 시장분석관 | 신호 강도 재평가 |
| 소싱 가능성 | 상품기획팀장 | 공급사 견적 |

**Go/Hold/Kill 결정 (CEO 결재)**:

```markdown
# Decision Memo: [제품명]

## 1. 무엇을 결정하는가
이 신제품을 만들 것인가.

## 2. 4개 인풋
- 시장: ...
- 재무: 시나리오 표 첨부
- 브랜드: 3축 매핑 (수면 과학 / 감성 / 프리미엄 중)
- 실행: 소싱 X주 / 디자인 X주 / 출시 X주

## 3. 추천: GO / HOLD / KILL
사유 3줄.

## 4. 가설
"~할 것이라 가정. 출시 X개월 후 ~ 지표로 검증."

## 5. 되돌릴 트리거
"~ 되면 라인업에서 제외."
```

## Stage 3: Build (4~12주, 카테고리에 따라)

**병렬 작업**:

| 작업 | 담당 | 기간 |
|---|---|---|
| 사양 정의 | 상품기획 + 운영 | 1주 |
| 발주 | 운영팀장 | 4~10주 |
| 패키징 디자인 | 디자이너 | 2주 |
| 제품 사진 촬영 | 디자이너 | 1주 |
| 상세페이지 작성 | `pdp-builder` + 마케팅팀장 | 1~2주 |
| 키워드 SEO | 마케팅팀장 + `keyword-optimizer` | 1주 |
| 브랜드실장 검수 | 브랜드실장 | 1주 (병렬) |

## Stage 4: Launch (1~2주)

**런칭 패키지**:
- 자사몰 PDP 등록 (운영팀장)
- 스마트스토어 등록 (운영팀장)
- 메타 광고 21종 빌드 (`meta-ad-factory` + 디자이너)
- 인스타 런칭 캠페인 (마케팅팀장)
- 카드뉴스 1건 (`card-news`)
- 네이버 블로그 2건 (`naver-blog-seo-writer`)
- 체험단 5명 발송 (`instagram-reviewer` 후보)
- 동봉물 (수면 가이드 카드 / 손글씨 카드)

**런칭 후 4주**:
- 매출 / ROAS / 리뷰 모니터링
- Stage 2 가설 검증
- 가설 실패 시 Hold 또는 KILL 결정

## 흔한 함정

1. **Discovery 너무 짧음** — 시장 신호 강 확인 안 하고 만들기 시작
2. **재무 시뮬레이션 단일 안** — 3 시나리오 필수
3. **브랜드실장 검수 늦음** — Stage 2 자문 + Stage 3 검수 모두 필요
4. **출시 후 가설 검증 X** — 4주 후 점검 안 하면 학습 0
