# 상품기획팀장 스킬 매핑

## Primary

| 스킬 | 용도 |
|---|---|
| `new-product-planner` | 신제품 13탭 (시장조사~런칭) |
| `product-scout` | 데이터 기반 기회 발굴 |
| `product-analyzer` | USP 추출 |
| `competitive-intelligence` | 경쟁 제품 비교 |
| `pdp-builder` | 상세페이지 (브랜드실장 검수 전제) |

## MCP 직접 사용

| MCP | 용도 |
|---|---|
| `naver-search.datalab_shopping_*` | 쇼핑 카테고리 트렌드 |
| `naver-search.search_shop` | 경쟁 제품 가격/스펙 |
| `media-dashboard` | 제품 사진 자산 관리 |

## Secondary

| 스킬 | 용도 |
|---|---|
| `keyword-optimizer` | 신제품 SEO 카피 |
| `xlsx` | 사양표 / 시뮬레이션 |
| `competitor-analyzer` (sub-agent) | 경쟁 제품 깊은 분석 |

## 협업 필수

| 부서 | 협업 시점 |
|---|---|
| **시장분석관** | 시장 신호 강도 검증 |
| **재무이사** | 가격 / 수익 시뮬레이션 |
| **브랜드실장** | 컨셉 brand DNA 정합 |
| **운영팀장** | 재고 / 발주 / 사양 |
| **마케팅팀장** | 출시 캠페인 |
| **디자이너** | 패키징 / 제품 비주얼 |

## 사용 금지

- ❌ 광고 카피 작성 (마케팅팀장 영역)
- ❌ 디자인 직접 (디자이너 영역)
- ❌ 단독 가격 결정 (재무이사 + CEO)
