# STEP 0 인터뷰 가이드

라이브 페이지 빌드 전 사용자에게서 받아야 할 정보를 자연스러운 대화로 수집한다.
**한 번에 한 질문, 답변마다 맞장구 + 다음 질문 이어가기**.

## 진행 원칙

1. **하나씩, 자연스럽게** — 한꺼번에 4-10개를 몰아 묻지 않음
2. 답변에 맞장구치면서 다음 항목으로 자연스럽게 넘어감
3. 사용자가 "잘 모르겠어"라고 하면 옵션 제시 또는 추천
4. **모든 항목 확정 후** 요약 + "이대로 빌드할까요?" 동의 게이트
5. 동의 받으면 `LiveSpec` JSON 작성 → `build_live.py --spec` 실행

---

## 필수 10개 항목 (질문 예시 + 매핑되는 슬롯)

### 1. 메인 제품
- 질문: "이번 라이브 메인 제품이 뭐예요?"
- 매핑: `product_name`
- 폴백: 사용자가 모르면 "썬데이허그 스토어에서 어떤 제품을 강조할 계획이세요?"

### 2. 상세페이지 경로
- 질문: "이 제품의 상세페이지 HTML 파일 경로 알려주세요. (예: `~/Desktop/output/상세페이지/sundayhug/sleepsack-silky-bamboo.html`)"
- 용도: 이미지 폴더(`images/{slug}/`) resolve. 제품 슬러그 추출.
- 폴백: 경로 모르면 → "그러면 이미지 폴더 경로 직접 알려주세요"

### 3. 라이브 일정
- 질문: "라이브 언제 진행하세요? 날짜 + 시간 + 어디 채널?"
- 매핑: `schedule_date`, `schedule_time`, `schedule_channel`
- 카운트다운: 별도로 묻지 않고 자동 계산 OR 인터뷰 마지막에 추가 슬롯 (`countdown_*`)
- 옵션: 채널 모르면 "네이버 스마트스토어 / 자사몰 / 카카오톡 라이브 중 어디?"

### 4. 호스트 정보
- 질문: "이번 라이브 호스트(진행자) 어떻게 되세요? 이름 + 역할 + 사진 경로 (있으면)"
- 매핑: `host_name`, `host_role`, `host_image`, `host_photo`, `host_quote_html`
- 폴백: "호스트 사진 없으면 일단 빈 자리로 두고 나중에 채울 수 있어요" → 11-host-recommendation 섹션 제외 또는 placeholder

### 5. 라이브 타이틀
- 질문: "라이브 메인 헤드라인 한 줄 + 서브 카피 한 줄 + 가장 핵심 혜택 한 줄"
- 매핑: `live_title_html`, `live_sub`, `live_benefit`
- 헤드라인은 `<br>` 줄바꿈 가능 — 슬롯명 끝에 `_html` 붙음

### 6. 가격
- 질문: "라이브 가격 / 정가 / 온라인몰가는?"
- 매핑: `live_price`, `original_price`, `price_online`, `price_save_amount`
- 폴백: 정가 모르면 "할인율로 알려주셔도 됩니다 — 자동 계산할게요"

### 7. 쿠폰
- 질문: "라이브 전용 쿠폰 있어요? (있으면) 코드 + 금액 + 조건"
- 매핑: `coupon_code`, `coupon_amount`, `coupon_condition`, `coupon_label`
- 없으면: 06-coupon 섹션 자동 제외

### 8. 라이브 혜택 4개
- 질문: "라이브 혜택 4개 정도 알려주세요. 각각 (아이콘 + 제목 + 설명 + 짧은 태그)"
- 매핑: `live_benefits` 배열 (4개 권장)
- 옵션: "구체적인 게 안 떠오르시면 보통 이런 거 넣어요: 라이브 한정 할인율, 오늘 발송, 사은품, 100일 환불"

### 9. 사은품
- 질문: "구매 고객 사은품 있어요? (있으면) 제목 + 설명 + 이미지"
- 매핑: `gifts` 배열 (1-3개)
- 없으면: 17-gift-event 섹션 자동 제외

### 10. 캠페인 톤 (팔레트 자동 매핑)
- 질문: "라이브 분위기를 어떻게 잡고 싶어요? (시즌 / 무드)"
- 자동 매핑 (월 또는 키워드 기반):

| 시즌 | 키워드 | 추천 팔레트 |
|---|---|---|
| 봄 (3-5월) | 어린이날, 가정의달, 출산 | `warm-spring` |
| 초여름 (6월) | 메쉬, 밤부, 친환경 | `fresh-garden` |
| 한여름 (7-8월) | 시원, 메쉬 라인 | `cool-summer` |
| 가을 (9-10월) | 추석, 가을 신상 | `cozy-autumn` |
| 겨울 (1-2월) | 신년, 한파, 트리플 | `gentle-winter` |
| 블랙프라이데이 (11월) | 블프, 연중 최대 할인 | `coral-sunset` |
| 연말 (12월) | 크리스마스, VIP, 프리미엄 | `midnight-luxe` |
| 무드 옵션 | 여아, 블러시 | `rose-dawn` |
|  | 신생아, 출산 축하 | `blush-touch` |
|  | 수면 캠페인, 야간 | `moonlit-calm` |
|  | 남아, 프리미엄 | `slate-mood` |
|  | (기본값) | `golden-hour` |

## 선택 추가 항목 (인터뷰 후반에 한 번 더 물음)

질문 예시: "기본 항목은 다 정리됐어요. 추가로 넣을 거 있으세요?"

| 항목 | 매핑 | 권장 |
|---|---|---|
| 번들 딜 | `bundles` 배열 | 다중 제품 라이브 |
| 세트 구성 | `set_items` | 세트 상품 |
| FAQ | `faqs` 배열 (3-5개) | 거의 항상 권장 — "상세페이지 FAQ 그대로 가져와도 돼요" |
| 리뷰 통계 | `review_avg_score`, `review_total_count`, `review_repurchase` | 실데이터 확인 |
| 리뷰 샘플 | `reviews` 배열 (3개) | 짧은 인용 + 익명 닉네임 |
| 사이즈 표 | `size_headers`, `size_rows` | 의류성 제품 |
| 인증 마크 | `cert_items` | OEKO-TEX 등 |

## 요약 + 동의 게이트 예시

```
📋 라이브 페이지 정리:
- 제품: 실키밤부 슬리핑백
- 상세페이지: ~/Desktop/output/상세페이지/sundayhug/sleepsack-silky-bamboo.html
- 일정: 2026.05.10 (일) 오후 8시 @ 네이버 쇼핑라이브
- 호스트: 사라쌤 (수면 코치)
- 타이틀: "엄마들의 꿀잠 시크릿 / 실키밤부 라이브 특가"
- 가격: 29,900원 (정가 39,900원, 25% 할인)
- 쿠폰: LIVE0510 - 5,000원 (5만원 이상 구매 시)
- 혜택 4개: 라이브 한정 30% / 오늘 발송 / 사은품 / 100일 환불
- 팔레트: warm-spring (5월 → 자동 매핑)
- 활성 섹션: 14개 (프리미엄 프리셋)

이대로 라이브 페이지 빌드 시작할까요? (Y/N)
```

Y → spec.json 작성 → `build_live.py --spec` 실행 → `export_png.py --campaign` 실행 → preview-grid 자동 안내.
N → 어떤 부분 수정할지 다시 물어보고 해당 항목만 다시 확인.
