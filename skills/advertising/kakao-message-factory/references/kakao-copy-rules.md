# 카카오 메시지 카피 작성 규칙

## 1. 알림톡 (07, 08) — 광고성 카피 절대 금지

알림톡은 정보성 메시지로 분류되어 사용자가 수신 거부할 수 없습니다. 따라서 카카오는 광고성 카피 사용을 엄격히 차단하며, 적발 시 채널 발송 권한이 박탈됩니다.

### 자동 차단 키워드 (`BANNED_WORDS_NOTIFICATION`)

```python
BANNED_WORDS_NOTIFICATION = [
    # 할인/세일 관련
    "할인", "%", "퍼센트", "%할인", "특가", "세일", "SALE", "sale",
    "최저가", "반값", "공짜", "무료증정", "사은품",
    # 프로모션 관련
    "프로모션", "이벤트", "EVENT", "쿠폰", "적립금", "포인트 적립",
    "선착순", "한정", "한정수량", "한정판매", "마감임박",
    # 광고 유도 표현
    "지금 구매", "지금 주문", "오늘만", "오늘까지", "단 하루",
    "놓치지마", "절호의 기회", "역대급", "역대 최저",
    # 강조 기호
    "★", "♥", "❤", "💝", "🎁", "🔥",
]
```

### 알림톡 허용 카피 패턴

✅ **OK (정보 전달)**:
- "주문하신 상품이 발송되었습니다"
- "결제가 정상 처리되었습니다"
- "회원가입을 환영합니다"
- "포인트 1,000P가 적립되었습니다" (포인트 안내는 사실 정보 → 허용. 단 "포인트 적립" 같이 행동 유도형은 차단)
- "예약 일정이 변경되었습니다"

❌ **차단**:
- "지금 50% 할인 받으세요"
- "쿠폰 발급 안내" (제목에 쿠폰 언급)
- "이벤트 참여 안내" (이벤트 언급)
- "선착순 100명!"

### 검열 모드

`kakao_validator.validate_copy_for_notification()`는 두 가지 모드 지원:

| 모드 | 동작 |
|---|---|
| `strict` | 키워드 1개라도 검출되면 빌드 차단 (기본값) |
| `warn` | 검출 키워드 표시 후 사용자 confirm 요청 |

## 2. 친구톡 — 톤별 글자수 한도

친구톡은 광고성 메시지로 키워드 제약은 없지만 글자수 한도가 엄격합니다.

### 와이드 이미지형 (02) — 76자 한도

본문(`km-info-bar-desc` 등)은 76자를 넘기면 카카오 콘솔에서 잘립니다.

| 톤 | 핵심 어조 | 글자수 권장 | 예시 |
|---|---|---|---|
| **emotional** (감성) | 라이프스타일 묘사, 감성 어휘 | 40~60자 | "아기의 첫 잠자리, 부드러운 밤부 원단으로 함께해요" |
| **informational** (정보) | 스펙/혜택 명시 | 30~50자 | "S/M/L 3사이즈 · 100% 오가닉 코튼" |
| **urgency** (긴급) | 한정/마감 강조 (단, 알림톡과 명확히 구분) | 25~40자 | "한정 수량, 곧 마감됩니다" |

### 캐러셀 커머스형 (05) — 상품명 20자

상품명은 20자 한도. 길어지면 자동 ellipsis(`...`) 처리되지만 시각적 손상 큼 → 17자 이내 권장.

✅ "ABC 접이식 아기침대 크림" (15자)
❌ "ABC 접이식 아기침대 크림 + 매트리스 풀세트" (24자, 잘림)

### 가격 표시 규칙

- 정가/할인가 모두 **숫자만** 입력 (예: `29900`)
- 통화 기호(원), 천단위 콤마는 템플릿이 CSS로 자동 처리
- 할인율은 정수 (예: `52`, `%`는 자동 추가)

```html
<!-- ✅ 올바른 사용 -->
<span class="km-info-bar-discount">52%</span>
<span class="km-info-bar-price">29,900원</span>
<div class="km-info-bar-orig">62,000원</div>
```

## 3. CTA 버튼 카피 (전체 공통)

| 가이드 | 권장 |
|---|---|
| 글자수 | 14자 이하 (모바일에서 줄바꿈 방지) |
| 동사 | 명확한 행동 동사 (구매하기, 자세히 보기, 신청하기) |
| 부정/모호 표현 | 금지 ("혹시 관심있다면" 등) |

✅ "지금 구매하기" / "자세히 보기" / "예약 신청" / "쿠폰 받기"
❌ "한번 둘러보세요 ▶" (이모지+15자, 잘릴 수 있음)

## 4. 캐러셀 카드 카피 일관성

캐러셀(04, 05)은 카드별 카피가 한 메시지로 묶여 보이므로:

1. **톤 일관성** — 인트로 카드가 emotional이면 모든 후속 카드도 emotional 유지
2. **CTA 동사 통일** — 모든 카드 "구매하기" 또는 모든 카드 "보러가기"로 통일
3. **가격 표기 통일** — 일부 카드에만 정가 취소선 표시하면 시각적 혼란

## 5. 자주 하는 실수 (실제 발송 거부 사례 기반)

| 실수 | 결과 | 대응 |
|---|---|---|
| 알림톡에 "쿠폰 안내"라는 제목 | 발송 거부 | "혜택 안내" 또는 "회원 안내"로 교체 |
| 친구톡에 1,000자 본문 | 잘림 (76자만 표시) | 짧게 다듬거나 텍스트형(FT)으로 변경 |
| 캐러셀 카드별 비율 다름 | 캐러셀 미작동 | 모든 카드 800×600 또는 모두 800×800으로 통일 |
| 알림톡에 "🎁" 이모지 | 광고성 분류 → 거부 | 이모지 제거 또는 친구톡으로 변경 |
| 가격에 "원" 직접 입력 (`29,900원원`) | 통화 중복 표시 | 숫자만 입력, 템플릿 CSS가 처리 |
